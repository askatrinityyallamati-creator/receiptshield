  <section class="method" id="method">
    <div class="wrap">
      <div class="section-head">
        <h2>How the seven stages work</h2>
        <p>ReceiptShield combines OCR, mathematical validation and image-based tampering detection instead of checking only the visual appearance of a receipt.</p>
      </div>
      <div class="method__grid">
        <article class="step-card"><span class="step-card__n">01</span><h3>Receipt Upload</h3>
          <p>The image is normalised, upscaled for legibility and kept entirely in the browser. EXIF and embedded-editor markers are inspected but never uploaded.</p></article>
        <article class="step-card"><span class="step-card__n">02</span><h3>OCR Extraction</h3>
          <p>A Tesseract engine runs in a web worker and returns raw text plus a word-level geometry table: bounding boxes, baselines and per-word confidence.</p></article>
        <article class="step-card"><span class="step-card__n">03</span><h3>Item / Price / Tax Detection</h3>
          <p>Lines are classified into items, modifiers, discounts, taxes and totals. Quantities, unit prices, percentages and currency amounts are parsed into numbers.</p></article>
        <article class="step-card"><span class="step-card__n">04</span><h3>Mathematical Validation</h3>
          <p>Every equation the receipt asserts gets recomputed: qty × unit against line totals, items against the subtotal, subtotal − discount + tax against the grand total.</p></article>
        <article class="step-card"><span class="step-card__n">05</span><h3>Visual Tampering Analysis</h3>
          <p>Error-level analysis exposes re-compression residue from pasted regions, tone mapping spots patches whose background does not match, and typography metrics catch odd font sizes, baselines and spacing.</p></article>
        <article class="step-card"><span class="step-card__n">06</span><h3>Suspicious Information Detection</h3>
          <p>Logic and statistics check the rest: amount columns that stop aligning, duplicate lines, missing tax, implausible rates, round-number edits and low-confidence clusters.</p></article>
        <article class="step-card"><span class="step-card__n">07</span><h3>Fraud Risk Report</h3>
          <p>Findings are weighted by severity into a 0–100 risk score, then presented with the evidence behind each one and an exportable JSON payload.</p></article>
      </div>

      <div class="innovate">
        <h3>Innovation</h3>
        <p>It combines <strong>OCR</strong>, <strong>mathematical validation</strong> and <strong>image-based tampering detection</strong> instead of checking only the visual appearance of a receipt, making it useful for expense verification and fraud detection.</p>
      </div>
    </div>
  </section>

  <!-- ───────────────────────── LIMITS ───────────────────────── -->
  <section class="limits" id="limits">
    <div class="wrap">
      <div class="section-head"><h2>What this can and cannot claim</h2></div>
      <div class="limits__grid">
        <div class="card">
          <h4>It is evidence, not proof</h4>
          <p>ReceiptShield is a heuristic triage tool. A flagged receipt is a reason to look closer, not a finding of fraud. Compression, scanning, glare and phone cameras all create artefacts that resemble tampering.</p>
        </div>
        <div class="card">
          <h4>Where it is strongest</h4>
          <p>Edited amounts, quantities or totals that break the arithmetic; text pasted from another font; patches whose background tone or noise does not match; and files that were re-saved by an image editor.</p>
        </div>
        <div class="card">
          <h4>Where it is blind</h4>
          <p>A forger who re-types the whole receipt in one font, keeps the arithmetic consistent and exports a clean PNG leaves little trace. Very low-resolution or heavily compressed receipts defeat the pixel-level stages.</p>
        </div>
        <div class="card">
          <h4>Privacy</h4>
          <p>Everything runs client-side. The receipt image is read locally through a canvas, the OCR engine is fetched from a CDN on first use, and nothing is transmitted to or stored on a server.</p>
        </div>
      </div>
    </div>
  </section>

/* ==========================================================================
   ReceiptShield — util.js
   Shared helpers: DOM, currency/number parsing, statistics, geometry.
   Exposes window.RS.util
   ========================================================================== */
(function (global) {
  'use strict';

  const RS = (global.RS = global.RS || {});

  /* ── DOM ─────────────────────────────────────────────────── */
  const $ = (sel, root) => (root || document).querySelector(sel);
  const $$ = (sel, root) => Array.from((root || document).querySelectorAll(sel));
  const el = (tag, attrs, children) => {
    const node = document.createElement(tag);
    if (attrs) for (const k in attrs) {
      if (k === 'class') node.className = attrs[k];
      else if (k === 'text') node.textContent = attrs[k];
      else if (k === 'html') node.innerHTML = attrs[k];
      else node.setAttribute(k, attrs[k]);
    }
    (children || []).forEach((c) => c && node.appendChild(c));
    return node;
  };
  const esc = (s) => String(s == null ? '' : s)
    .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;').replace(/'/g, '&#39;');

  /* ── currency ────────────────────────────────────────────── */
  const CURRENCY = /(?:₹|rs\.?|inr|usd|sgd|aed|eur|gbp|chf|myr|thb|\$|€|£|¥)/gi;

  /** Detect the dominant currency glyph in a block of text. */
  function detectCurrency(text) {
    if (/₹/.test(text)) return { symbol: '₹', code: 'INR' };
    if (/\b(rs\.?|inr)\b/i.test(text)) return { symbol: '₹', code: 'INR' };
    if (/€/.test(text) || /\beur\b/i.test(text)) return { symbol: '€', code: 'EUR' };
    if (/£/.test(text) || /\bgbp\b/i.test(text)) return { symbol: '£', code: 'GBP' };
    if (/\$/.test(text) || /\busd\b/i.test(text)) return { symbol: '$', code: 'USD' };
    if (/¥/.test(text)) return { symbol: '¥', code: 'JPY' };
    return { symbol: '', code: '' };
  }

  /**
   * Parse a money-ish string into a number.
   * Handles "₹1,500.00", "1.500,00" (European), "(120.00)" (negative),
   * "1,234", "1500.5", "12 500.00" and trailing CR/DR markers.
   * Returns NaN when there is no usable number.
   */
  function parseAmount(raw) {
    if (raw == null) return NaN;
    if (typeof raw === 'number') return raw;

    let s = String(raw).trim();
    if (!s) return NaN;

    s = s.replace(CURRENCY, ' ');
    let negative = false;
    if (/^\(.*\)$/.test(s.trim())) { negative = true; s = s.replace(/[()]/g, ' '); }
    if (/\b(?:cr|dr)\b\s*$/i.test(s)) negative = /cr\s*$/i.test(s.trim()); // credit = refund
    if (/^\s*-/.test(s)) { negative = true; }

    s = s.replace(/[^0-9.,]/g, '').replace(/^[.,]+/, '');
    if (!s) return NaN;

    const lastDot = s.lastIndexOf('.');
    const lastComma = s.lastIndexOf(',');
    const decSep = lastDot > lastComma ? '.' : (lastComma > lastDot ? ',' : '');

    if (!decSep) {
      // pure digits, possibly long — treat as integer
      const n = Number(s.replace(/[.,]/g, ''));
      return Number.isFinite(n) ? (negative ? -n : n) : NaN;
    }

    const intPart = s.slice(0, s.lastIndexOf(decSep)).replace(/[.,]/g, '');
    const fracPart = s.slice(s.lastIndexOf(decSep) + 1);

    // A single separator followed by exactly 3 digits is far more likely a
    // thousands separator ("1,500") than a decimal ("1.500").
    if (fracPart.length === 3 && intPart.length > 0 && (lastDot < 0 || lastComma < 0)) {
      const merged = Number(intPart + fracPart);
      return Number.isFinite(merged) ? (negative ? -merged : merged) : NaN;
    }
    // "1,50" or "1,5" -> decimal comma. Trailing "0" groups are separators.
    const frac = fracPart.replace(/[.,].*$/, '');
    if (frac.length > 3) {
      const merged = Number(intPart + fracPart.replace(/[^0-9]/g, ''));
      return Number.isFinite(merged) ? (negative ? -merged : merged) : NaN;
    }

    const n = Number((intPart || '0') + '.' + (frac || '0'));
    if (!Number.isFinite(n)) return NaN;
    return negative ? -n : n;
  }

  /** Extract every trailing/embedded money token from a string. */
  function moneyTokens(text) {
    const re = /(?:₹|rs\.?|inr|\$|€|£|¥)?\s*\(?-?\d[\d.,]*\)?(?:\s*(?:cr|dr))?/gi;
    const out = [];
    let m;
    while ((m = re.exec(text)) !== null) {
      const value = parseAmount(m[0]);
      if (Number.isFinite(value) && /\d/.test(m[0])) {
        out.push({ raw: m[0].trim(), value, index: m.index });
      }
      if (m.index === re.lastIndex) re.lastIndex++;
    }
    return out;
  }

  /** The last money-looking token on a line, or null. */
  function trailingAmount(text) {
    const tokens = moneyTokens(text);
    if (!tokens.length) return null;
    const last = tokens[tokens.length - 1];
    // must actually sit at the end of the line (allow trailing junk like units)
    const tail = text.slice(last.index + last.raw.length).replace(/[.\s:|\-–—_]+$/, '');
    if (tail.length > 0 && !/^[a-z]{1,4}$/i.test(tail)) return null;
    return { ...last, before: text.slice(0, last.index).trim() };
  }

  function fmtMoney(value, symbol) {
    if (!Number.isFinite(value)) return '—';
    const sym = symbol === undefined ? '' : symbol;
    const fixed = Math.abs(value) >= 1000
      ? value.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 })
      : value.toFixed(2);
    return (value < 0 ? '-' : '') + sym + fixed.replace('-', '');
  }

  function fmtDelta(value) {
    if (!Number.isFinite(value)) return '—';
    const s = value.toFixed(2);
    return (value > 0 ? '+' : '') + s;
  }

  const round2 = (n) => Math.round((n + Number.EPSILON) * 100) / 100;

  /* ── statistics ──────────────────────────────────────────── */
  function median(values) {
    const a = values.filter(Number.isFinite).slice().sort((x, y) => x - y);
    if (!a.length) return NaN;
    const mid = a.length >> 1;
    return a.length % 2 ? a[mid] : (a[mid - 1] + a[mid]) / 2;
  }
  function mean(values) {
    const a = values.filter(Number.isFinite);
    return a.length ? a.reduce((s, x) => s + x, 0) / a.length : NaN;
  }
  /** Median absolute deviation — robust spread measure. */
  function mad(values) {
    const med = median(values);
    if (!Number.isFinite(med)) return NaN;
    return median(values.filter(Number.isFinite).map((v) => Math.abs(v - med)));
  }
  /** Robust z-score using median/MAD (0.6745 scales MAD to sigma). */
  function robustZ(value, med, spread) {
    if (!Number.isFinite(value) || !Number.isFinite(med) || !Number.isFinite(spread)) return 0;
    if (spread <= 1e-9) return value === med ? 0 : 999;
    return (0.6745 * (value - med)) / spread;
  }
  function percentile(values, p) {
    const a = values.filter(Number.isFinite).slice().sort((x, y) => x - y);
    if (!a.length) return NaN;
    const idx = Math.min(a.length - 1, Math.max(0, Math.round((p / 100) * (a.length - 1))));
    return a[idx];
  }

  /* ── geometry ────────────────────────────────────────────── */
  const box = (w) => ({ x: w.x0, y: w.y0, w: w.x1 - w.x0, h: w.y1 - w.y0 });
  const boxArea = (b) => Math.max(0, b.w) * Math.max(0, b.h);
  function overlapRatio(a, b) {
    const x = Math.max(0, Math.min(a.x + a.w, b.x + b.w) - Math.max(a.x, b.x));
    const y = Math.max(0, Math.min(a.y + a.h, b.y + b.h) - Math.max(a.y, b.y));
    const inter = x * y;
    const denom = Math.min(boxArea(a), boxArea(b));
    return denom > 0 ? inter / denom : 0;
  }

  /* ── misc ────────────────────────────────────────────────── */
  const clamp = (n, lo, hi) => Math.min(hi, Math.max(lo, n));
  const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

  RS.util = {
    $, $$, el, esc, clamp, sleep, round2,

  };

/* ==========================================================================
   ReceiptShield — samples.js
   Builds two synthetic receipt files entirely on the client so the demo can
   run with no network and no personal data:

     genuine  — a clean, arithmetically consistent receipt
     tampered — the same receipt after a forged "save": two amounts are pasted
                in a different font, shifted off the amount column, over a
                patch whose paper tone does not quite match, and sitting on a
                re-compression boundary.

   The tampered file is produced by first JPEG-encoding the genuine receipt
   (simulating "the file as it was originally saved") and then drawing the
   forged values on top of the decoded pixels. That is exactly the history
   error-level analysis is designed to reveal.

   Exposes window.RS.samples
   ========================================================================== */

  }

   * Apply the fraud to a copy of the document.
   * Two numbers change; both are marked `paste` so the renderer draws them the
   * way a forger would — different typeface, nudged off the column, on top of
   * a background patch lifted from somewhere else.
   */
  function tamper(doc) {
    doc.forEach((b) => {
      if (b.t === 'item' && b.name === 'Club Sandwich') {
        b.amount = 700.00;   // printed line total no longer equals qty x unit (200.00)
        b.paste = true;
      }
      if (b.t === 'total') {
        b.right = 1708.50;   // ₹708.50 rewritten as ₹1,708.50
        b.paste = true;
      }
    });
    return doc;
  }

  const PASTE_STYLE = {
    bg: '#f9f9ee',                 // paper tone that does not match the sheet
    font: 'bold 25px Georgia, "Times New Roman", serif',
    dx: 7,
    dy: 1,
  };

  /** The imaging tool a real forgery is most often re-saved through. */
  const EDITOR = 'Adobe Photoshop 24.0 (Windows)';

  /* ── text export ─────────────────────────────────────────── */
  function docToText(doc) {
    const out = [];
    // Only numeric rows are money. Invoice numbers, dates and payment names
    // must be passed through untouched.
    const amt = (v) => (typeof v === 'number' ? v.toFixed(2) : String(v === null || v === undefined ? '' : v));
    doc.forEach((b) => {
      if (b.t === 'rule') return;
      if (b.t === 'kv') { out.push(padRow(b.left, amt(b.right))); return; }
      if (b.t === 'item') {
        const desc = b.qty + ' x ' + b.name;
        out.push(padTriple(desc, amt(b.unit), amt(b.amount)));
        return;
      }
      if (b.t === 'total') { out.push(padRow(b.left, amt(b.right))); return; }
      if (b.t === 'title' || b.t === 'label') { out.push(b.text); return; }
      out.push(b.text);
    });
    return out.join('\n');
  }
  function padRow(left, right) {
    const width = 40;
    const gap = Math.max(1, width - stripTags(left).length - String(right).length);
    return left + ' '.repeat(gap) + right;
  }
  function padTriple(desc, unit, amount) {
    const width = 46;
    const gap = Math.max(1, width - desc.length - unit.length - amount.length);
    return desc + ' '.repeat(gap) + unit + '  ' + amount;
  }
  const stripTags = (s) => String(s).replace(/<[^>]+>/g, '');

  /* ── canvas helpers ──────────────────────────────────────── */
  function blank(w, h, fill) {
    const c = document.createElement('canvas');
    c.width = w; c.height = h;
    const ctx = c.getContext('2d', { willReadFrequently: true });
    if (fill) { ctx.fillStyle = fill; ctx.fillRect(0, 0, w, h); }
    return c;
  }

  function drawDoc(doc) {
    const LINE = 34;
    const rough = 260 + doc.length * LINE;
    const c = blank(W, rough, PAPER);
    const ctx = c.getContext('2d');
    ctx.fillStyle = PAPER;
    ctx.fillRect(0, 0, W, rough);
    ctx.textBaseline = 'alphabetic';
    ctx.fillStyle = '#12161c';

    let y = 96;
    const pasteOps = [];

    doc.forEach((b) => {
      const pasted = !!b.paste;
      const baseFont = '22px ' + FONT;

      if (b.t === 'rule') {
        ctx.strokeStyle = '#12161c';
        ctx.lineWidth = 1.4;
        ctx.beginPath();
        ctx.moveTo(PAD, y - 12.5);
        ctx.lineTo(RIGHT, y - 12.5);
        ctx.stroke();
        y += 16;
        return;
      }

      // background patch first, so pasted text sits on mismatched paper
      if (pasted) {
        ctx.fillStyle = PASTE_STYLE.bg;
        ctx.fillRect(PAD - 14 + PASTE_STYLE.dx, y + PASTE_STYLE.dy - 24, RIGHT - PAD + 28, 34);
        ctx.fillStyle = '#12161c';
      }

      const dx = pasted ? PASTE_STYLE.dx : 0;
      const dy = pasted ? PASTE_STYLE.dy : 0;
      const font = pasted ? PASTE_STYLE.font : baseFont;
      ctx.font = font;

      if (b.t === 'title') {
        ctx.font = 'bold 27px ' + FONT;
        const w = ctx.measureText(b.text).width;
        ctx.fillText(b.text, (W - w) / 2, y + dy);
        y += 42;
      } else if (b.t === 'center') {
        const w = ctx.measureText(b.text).width;
        ctx.fillText(b.text, (W - w) / 2, y + dy);
        y += LINE;
      } else if (b.t === 'label') {
        ctx.font = 'bold 22px ' + FONT;
        ctx.fillText(b.text, PAD, y + dy);
        y += LINE - 4;
      } else if (b.t === 'kv') {
        ctx.fillText(b.left, PAD, y + dy);
        rightAlign(ctx, String(b.right), RIGHT + dx, y + dy);
        y += LINE;
      } else if (b.t === 'item') {
        ctx.fillText(b.qty + ' x ' + b.name, PAD, y + dy);
        ctx.fillText(U.parseAmount(String(b.unit)).toFixed(2), UNIT_COL - ctx.measureText(U.parseAmount(String(b.unit)).toFixed(2)).width, y + dy);
        rightAlign(ctx, U.parseAmount(String(b.amount)).toFixed(2), RIGHT + dx, y + dy);
        y += LINE;
      } else if (b.t === 'total') {
        ctx.font = pasted ? PASTE_STYLE.font : 'bold 25px ' + FONT;
        ctx.fillText(b.left, PAD, y + dy);
        rightAlign(ctx, U.parseAmount(String(b.right)).toFixed(2), RIGHT + dx, y + dy);
        y += 44;
      }

      if (pasted) {
        pasteOps.push({
          x0: PAD - 16 + PASTE_STYLE.dx,
          x1: RIGHT + 16,
          y0: y - 46 + PASTE_STYLE.dy,
          y1: y + 6 + PASTE_STYLE.dy,
        });
      }
    });

    // trim to content
    const height = Math.min(rough, Math.ceil(y + 70));
    const out = blank(W, height, PAPER);
    out.getContext('2d').drawImage(c, 0, 0);
    const ctx2 = out.getContext('2d');
    grainify(ctx2, W, height, 1.4);
    return { canvas: out, pasteOps };
  }

  function rightAlign(ctx, text, right, y) {
    ctx.fillText(text, right - ctx.measureText(text).width, y);
  }

  /** Very light paper grain so no region is mathematically flat. */
  function grainify(ctx, w, h, amp) {
    const img = ctx.getImageData(0, 0, w, h);
    const d = img.data;
    for (let i = 0; i < d.length; i += 4) {
      if (d[i] > 250 && d[i + 1] > 250 && d[i + 2] > 250 && Math.random() < 0.35) continue;
      const n = (Math.random() - 0.5) * 2 * amp;
      d[i] += n; d[i + 1] += n; d[i + 2] += n;
    }
    ctx.putImageData(img, 0, 0);
  }

  /* ── JPEG round-trip ─────────────────────────────────────── */
  /** Encode a canvas to JPEG and decode it back, giving it real JPEG history. */
  function jpegRoundTrip(canvas, quality) {
    return new Promise((resolve) => {
      canvas.toBlob(async (blob) => {
        const bmp = await createImageBitmap(blob);
        const c = blank(canvas.width, canvas.height);
        c.getContext('2d').drawImage(bmp, 0, 0);
        bmp.close();
        resolve(c);
      }, 'image/jpeg', quality);
    });
  }

  /**
   * Export as PNG. Lossless on purpose: the two forged regions carry a different
   * compression history from the rest of the sheet, and a lossy export would
   * homogenise it and erase the very evidence error-level analysis looks for.
   * Pass `software` to stamp the file the way an image editor would.
   */
  function toPng(canvas, software) {
    return new Promise((resolve) => {
      canvas.toBlob(async (blob) => {
        const bytes = await blob.arrayBuffer();
        const out = software
          ? new Blob([injectPngText(bytes, 'Software', software)], { type: 'image/png' })
          : blob;
        resolve({ url: URL.createObjectURL(out), blob: out, name: 'receipt.png', type: 'image/png' });
      }, 'image/png');
    });
  }

  const CRC_TABLE = (() => {
    const t = new Uint32Array(256);
    for (let n = 0; n < 256; n++) {
      let c = n;
      for (let k = 0; k < 8; k++) c = (c & 1) ? (0xedb88320 ^ (c >>> 1)) : (c >>> 1);
      t[n] = c >>> 0;
    }
    return t;
  })();
  function crc32(bytes) {
    let c = 0xffffffff;
    for (let i = 0; i < bytes.length; i++) c = CRC_TABLE[(c ^ bytes[i]) & 0xff] ^ (c >>> 8);
    return (c ^ 0xffffffff) >>> 0;
  }

  /**
   * Insert a tEXt chunk after IHDR. This is how a PNG records the software that
   * wrote it, and it is what the suspicious-file check looks for.
   */
  function injectPngText(buffer, keyword, text) {
    const bytes = new Uint8Array(buffer);
    const SIG = [137, 80, 78, 71, 13, 10, 26, 10];
    if (bytes.length < 33 || !SIG.every((b, i) => bytes[i] === b)) return buffer;
    if (bytes[12] !== 0x49 || bytes[13] !== 0x48 || bytes[14] !== 0x44 || bytes[15] !== 0x52) return buffer;

    const ihdrLen = (bytes[8] << 24) | (bytes[9] << 16) | (bytes[10] << 8) | bytes[11];
    const insertAt = 8 + 4 + 4 + ihdrLen + 4;   // right after the IHDR chunk

    const payload = new Uint8Array(new TextEncoder().encode(keyword + '\u0000' + text));
    const chunk = new Uint8Array(4 + 4 + payload.length + 4);
    const view = new DataView(chunk.buffer);
    view.setUint32(0, payload.length);
    chunk[4] = 0x74; chunk[5] = 0x45; chunk[6] = 0x58; chunk[7] = 0x74;  // 'tEXt'
    chunk.set(payload, 8);
    view.setUint32(8 + payload.length, crc32(chunk.subarray(4, 8 + payload.length)));

    const out = new Uint8Array(bytes.length + chunk.length);
    out.set(bytes.subarray(0, insertAt), 0);
    out.set(chunk, insertAt);
    out.set(bytes.subarray(insertAt), insertAt + chunk.length);
    return out.buffer;
  }

  /* ── public API ──────────────────────────────────────────── */
  /**
   * Build a sample receipt.
   * @param {'genuine'|'tampered'} kind
   * @returns {Promise<{url, blob, name, text, truth}>}
   */
  async function build(kind) {
    const doc = kind === 'tampered' ? tamper(genuineDoc()) : genuineDoc();
    const text = docToText(doc);

    let working = { canvas: drawDoc(doc).canvas, pasteOps: [] };
    let file;

    if (kind === 'tampered') {
      // The sheet was forwarded as a heavily re-compressed JPEG long before the
      // forgery landed, so its pixels are smoothed and its high-frequency detail
      // is gone. The snippet the forger pasted came from somewhere else at high
      // quality, so it carries a different compression history — and it is that
      // mismatch, preserved in the lossless export, that error-level analysis
      // measures.
      const aged = await jpegRoundTrip(working.canvas, 0.70);
      const forgedRaw = drawDoc(doc);
      const forged = { canvas: await jpegRoundTrip(forgedRaw.canvas, 0.95), pasteOps: forgedRaw.pasteOps };

      const base = blank(W, aged.height);
      const bctx = base.getContext('2d', { willReadFrequently: true });
      bctx.drawImage(aged, 0, 0);
      forged.pasteOps.forEach((op) => {
        const sx = Math.max(0, U.clamp(op.x0 - 14, 0, base.width));
        const sy = Math.max(0, U.clamp(op.y0 - 12, 0, base.height));
        const sw = Math.min(op.x1 - op.x0 + 30, base.width - sx);
        const sh = Math.min(op.y1 - op.y0 + 26, base.height - sy);
        if (sw <= 0 || sh <= 0) return;
        bctx.drawImage(forged.canvas, sx, sy, sw, sh, sx, sy, sw, sh);
      });

      working.pasteOps = forged.pasteOps;
      file = await toPng(base, EDITOR);
    } else {
      file = await toPng(working.canvas);
    }
    return {
      ...file,
      text,
      truth: {
        kind,
        note: kind === 'tampered'
          ? 'Two amounts were rewritten: “Club Sandwich” line total ₹200.00 → ₹700.00 and “GRAND TOTAL” ₹708.50 → ₹1,708.50, pasted over an already-compressed copy of the receipt and re-saved through an image editor.'

   ReceiptShield — ocr.js
   Stage 2: OCR extraction.

   Wraps Tesseract.js in a single reusable worker and turns its word-level TSV
   output into something the rest of the pipeline can reason about: words with

(function (global) {
  'use strict';

  const RS = global.RS;
  const U = RS.util;

  let workerPromise = null;
  let currentLogger = null;

  /** Is the Tesseract library on the page? */
  function available() {
    return typeof global.Tesseract !== 'undefined' && typeof global.Tesseract.createWorker === 'function';
  }

  const PHASES = [
    [/loading tesseract core/i, 'Loading OCR engine'],
    [/initializing tesseract/i, 'Starting OCR engine'],
    [/loading language traineddata/i, 'Downloading language data'],
    [/initializing api/i, 'Initialising recogniser'],
    [/recognizing text/i, 'Reading the receipt'],
  ];

    for (const [re, label] of PHASES) if (re.test(status || '')) return label;
    return status ? String(status) : 'Working…';

  /** Lazily create (and memoise) the shared Tesseract worker. */
  function ensureWorker() {
    if (workerPromise) return workerPromise;

      return Promise.reject(new Error(
        'The OCR engine could not be loaded from the CDN. Check your connection, ' +
        'or switch to “Paste text” mode to run the validation engine on its own.'
      ));

      const worker = await global.Tesseract.createWorker('eng', 1, {
        logger: (m) => { if (currentLogger) currentLogger(m); },
        errorHandler: (e) => console.error('[tesseract]', e),

        preserve_interword_spaces: '1',

      workerPromise = null;               // allow a retry after a failed load
      throw err;

    return workerPromise;

  /**
   * Prepare an OCR-friendly copy of the receipt. The original pixels are left
   * untouched — visual forensics must analyse what the user actually has.
   */
  function preprocess(source, targetWidth) {
    const sw = source.width || source.naturalWidth;
    const sh = source.height || source.naturalHeight;
    const scale = U.clamp((targetWidth || 2000) / sw, 1, 3);
    const w = Math.round(sw * scale);
    const h = Math.round(sh * scale);

    canvas.width = w; canvas.height = h;

    ctx.imageSmoothingEnabled = true;
    ctx.imageSmoothingQuality = 'high';
    ctx.drawImage(source, 0, 0, w, h);

    // scans where this measurably improves recognition.
    const img = ctx.getImageData(0, 0, w, h);
    const d = img.data;
    const hist = new Uint32Array(256);
    for (let i = 0; i < d.length; i += 4) {
      const g = (d[i] * 0.299 + d[i + 1] * 0.587 + d[i + 2] * 0.114) | 0;
      d[i] = d[i + 1] = d[i + 2] = g;
      hist[g]++;
    }
    const total = (w * h) || 1;
    let lo = 0, hi = 255, acc = 0;
    for (let v = 0; v < 256; v++) { acc += hist[v]; if (acc > total * 0.02) { lo = v; break; } }
    acc = 0;
    for (let v = 255; v >= 0; v--) { acc += hist[v]; if (acc > total * 0.02) { hi = v; break; } }
    const span = Math.max(1, hi - lo);
    const lut = new Uint8ClampedArray(256);
    for (let v = 0; v < 256; v++) lut[v] = U.clamp(((v - lo) * 255) / span, 0, 255);
    for (let i = 0; i < d.length; i += 4) {
      const g = lut[d[i]];
      d[i] = d[i + 1] = d[i + 2] = g;
    }
    ctx.putImageData(img, 0, 0);
    return canvas;
  }

  function parseTsv(tsv) {

    if (!tsv) return words;
    const rows = String(tsv).split(/\r?\n/);

        x1: Math.max(...ws.map((w) => w.x1)),

        y1: Math.max(...ws.map((w) => w.y1)),
        height: hMed,

        center: ws.reduce((s, w) => s + (w.y0 + w.y1) / 2, 0) / ws.length,
        conf: U.mean(ws.map((w) => w.conf)),
        minConf: Math.min(...ws.map((w) => w.conf)),
        width: Math.max(...ws.map((w) => w.x1)) - Math.min(...ws.map((w) => w.x0)),

      });
    });

  }

  /** Rebuild a line of text, restoring a space where the words were far apart. */
  function joinWords(ws) {
    let out = '';
    for (let i = 0; i < ws.length; i++) {

      if (i === 0) { out = w.text; continue; }

      const ref = Math.max(1, U.median(ws.map((x) => x.y1 - x.y0)));
      const spaces = gap > ref * 1.6 ? (gap > ref * 4 ? 4 : 2) : 1;
      out += ' '.repeat(spaces) + w.text;
    }
    return out;
  }

/* ==========================================================================
   ReceiptShield — parse.js
   Stage 3: item / price / tax detection.

   Turns raw text (plus OCR geometry when available) into a structured receipt:
   line items with quantity, unit price and line total; discount, tax and
   rounding rows; and the totals the document claims to assert.

   Every value keeps a back-reference to the line and, when present, the exact
   OCR word box it came from, because stage 5 reasons about alignment,
   type size and confidence of those very boxes.

   Exposes window.RS.parse
   ========================================================================== */
(function (global) {
  'use strict';

  const RS = global.RS;
  const U = RS.util;

  /* ── number scanning ─────────────────────────────────────── */
  const CURRENCY_TOKEN = /(?:₹|Rs\.?|INR|\$|€|£|¥)/i;

  /** Blank out dates and times so their digits are never read as amounts. */
  function maskDatesTimes(text) {
    return text
      .replace(/\b\d{1,4}[\/.\-]\d{1,2}[\/.\-]\d{2,4}\b/g, (m) => ' '.repeat(m.length))
      .replace(/\b\d{1,2}:\d{2}(?::\d{2})?\s*(?:am|pm)?\b/gi, (m) => ' '.repeat(m.length))
      .replace(/\b\d{1,2}\s*(?:am|pm)\b/gi, (m) => ' '.repeat(m.length));
  }

  const AMOUNT_RE = new RegExp([
    '(?:₹|Rs\\.?|INR|\\$|€|£|¥)\\s*-?\\(?\\d[\\d,]*(?:\\.\\d{1,2})?\\)?', // symbol-led
    '-?\\(?\\d{1,3}(?:[,\\u00a0 ]\\d{2,3})+(?:\\.\\d{1,2})?\\)?',        // grouped
    '-?\\(?\\d+\\.\\d{1,2}\\)?',                                          // decimal
    '-?\\(?\\d{2,7}\\)?',                                                // bare integer
  ].join('|'), 'gi');

  function isBoundaryBefore(ch) {
    return !ch || !/[0-9A-Za-z.,\/]/.test(ch);
  }
  function isBoundaryAfter(ch) {
    return !ch || !/[0-9A-Za-z.,\/:%]/.test(ch);
  }

  /**
   * Find money-looking tokens with their positions.
   * Boundary tests plus date/time masking are what keep invoice ids,
   * GSTINs, phone numbers and tax rates out of the amount list.
   */
  function scanAmounts(rawText, opts) {
    const relaxed = !!(opts && opts.relaxed);
    // maskDatesTimes preserves length, so the second pass can safely rebuild a
    // decimal separator that OCR misread as a colon ("35:5" for "35.5").
    const text = maskDatesTimes(rawText).replace(/(\d)[:;](\d{1,2})(?=\s|$)/g, '$1.$2');
    const out = [];
    AMOUNT_RE.lastIndex = 0;
    let m;
    while ((m = AMOUNT_RE.exec(text)) !== null) {
      if (m.index === AMOUNT_RE.lastIndex) AMOUNT_RE.lastIndex++;
      const token = m[0];
      const before = text[m.index - 1];
      const after = text[m.index + token.length];
      if (!isBoundaryBefore(before) || !isBoundaryAfter(after)) continue;
      if (!/\d/.test(token)) continue;

      const digits = token.replace(/[^0-9]/g, '');
      const hasSymbol = CURRENCY_TOKEN.test(token);
      const hasDecimal = /\.\d{1,2}\)?$/.test(token.trim());
      const hasGrouping = /[\d][,\u00a0 ]\d{2,3}/.test(token);
      // Without a currency symbol, a decimal point or digit grouping, a short
      // integer is a quantity or a percentage and a long one is an identifier:
      // a postal code, phone number, invoice id or tax registration number.
      // On a row we already know is a money row (subtotal, tax, total), a bare
      // integer is accepted because "Subtotal 710" is a perfectly normal print.
      if (!hasSymbol && !hasDecimal && !hasGrouping) {
        if (digits.length >= 6) continue;
        if (digits.length <= 3 && !relaxed) continue;
      }

      const value = U.parseAmount(token);
      if (!Number.isFinite(value)) continue;
      out.push({
        raw: token.trim(),
        value,
        index: m.index,
        end: m.index + token.length,
        hasSymbol,
        hasDecimal,
      });
    }
    return out;
  }

  /** Repair the classic OCR digit confusions inside an obviously numeric token. */

    const digits = (token.match(/\d/g) || []).length;
    const letters = (token.match(/[A-Za-z]/g) || []).length;
    if (!digits || letters === 0 || letters > digits) return token;

      .replace(/[OoQ]/g, '0')
      .replace(/[Il|]/g, '1')
      .replace(/[Ss]/g, '5')
      .replace(/[Bb]/g, '8')

    { key: 'roundOff', kind: 'roundoff', re: /^round(?:ing)?[\s\-_.]*off\b/i },
    { key: 'taxable', kind: 'taxable', re: /^(?:taxable\s+(?:value|amount|total)|net\s+(?:amount|total)|amount\s+before\s+tax|pre[\s\-]?tax\s+total)\b/i },

  function classify(lineText) {
    const t = lineText.trim();
    if (!t) return { kind: 'blank' };
    if (/^[\-=_*·•~\s]{3,}$/.test(t)) return { kind: 'rule' };
    // A payment-method row is metadata even though it starts with "paid":
    // it names a channel, and any digits on it are a masked card number.
    if (/\b(?:paid\s+by|paid\s+via|payment\s+(?:method|mode)|tender\s+type|card\s*(?:no\.?|#)|upi|visa|mastercard|amex|rupay)\b/i.test(t)

      return { kind: 'meta', key: 'payment', value: t.replace(/\s{2,}/g, ' ').trim() };
    }

    for (const p of META_PATTERNS) {

      if (m) return { kind: 'meta', key: p.key, value: m[1] };
    }
    return { kind: 'text' };
  }

  /* ── item parsing ────────────────────────────────────────── */
  const MONEY_ROWS = ['subtotal', 'taxable', 'discount', 'tax', 'total', 'tendered', 'change', 'roundoff'];

  const QTY_PREFIX = /^\s*(\d{1,3}(?:\.\d{1,2})?)\s*(?:x|×|\*|@|nos?\.?|pcs?\.?|qty\.?)\s+/i;
  const QTY_BARE = /^\s*(\d{1,3})\s+(?=[A-Za-z])/;

  function parseItemLine(text, amounts, geo) {
    const tokens = amounts.slice().sort((a, b) => a.index - b.index);
    if (!tokens.length) return null;

    const last = tokens[tokens.length - 1];
    const second = tokens.length > 1 ? tokens[tokens.length - 2] : null;

    // the printed line total must be the final token on the line
    const tail = text.slice(last.end).replace(/[\s.\-–—_|:]*$/, '');
    if (tail.length > 0 && !/^[A-Za-z%]{1,4}$/.test(tail)) return null;

    let name = text.slice(0, second ? second.index : last.index);
    let qty = null;
    let unit = null;
    let amount = last.value;

    const qm = name.match(QTY_PREFIX);
    if (qm) {
      qty = U.parseAmount(qm[1]);
      name = name.slice(qm[0].length);
    } else {
      const qb = name.match(QTY_BARE);
      if (qb) {
        qty = U.parseAmount(qb[1]);
        name = name.slice(qb[0].length);
      }
    }

    // A second trailing number is the unit-price column. Take it as printed even
    // when it disagrees with the line total — that disagreement is the finding.
    let unitStated = false;
    if (second && Number.isFinite(second.value) && second.value > 0) {
      const cand = second.value;
      unit = cand;
      unitStated = true;
      if (qty === null) {
        const ratio = amount / cand;
        const ri = Math.round(ratio);
        if (ri >= 1 && ri <= 99 && Math.abs(ratio - ri) <= 0.02) qty = ri;
      }
    }

    name = name
      .replace(/[\s.\-–—_|:]+$/, '')
      .replace(/\s{2,}/g, ' ')
      .trim();

    if (!name || !/[A-Za-z]/.test(name)) return null;
    if (name.length > 60) return null;

    const derived = !unitStated;
    if (derived) {
      const q = qty === null ? 1 : qty;
      unit = q > 0 ? U.round2(amount / q) : amount;
    }

    return {
      name,
      qty: qty === null ? 1 : qty,
      qtyStated: qty !== null,
      unit,
      unitStated,
      unitDerived: derived,
      amount,
      raw: text.trim(),
      geo: geo || null,
    };
  }

  /* ── geometry helpers ────────────────────────────────────── */
  /** Box/confidence of the nth word from the end of an OCR line. */
  function wordFromEnd(line, n) {

      conf: w.conf,
      x0: w.x0, x1: w.x1, y0: w.y0, y1: w.y1,

      baseline: w.y1,
    };

        minConf: line.minConf,
        lastWord: wordFromEnd(line, 0),
        unitWord: wordFromEnd(line, 1),
      };

      if (cls.kind === 'meta') {
        if (cls.value && !meta[cls.key]) meta[cls.key] = cls.value;
        if (amountTokens.length) {
          misc.push({ lineIndex, text: text.trim(), amounts: amountTokens.map((a) => a.value) });
        }
        return;
      }

      if (isMoneyRow) {
        if (!amountTokens.length) {
          suspiciousText.push({ lineIndex, text: text.trim(), reason: 'label without an amount' });
          return;
        }
        const amountToken = amountTokens[amountTokens.length - 1];
        const amount = amountToken.value;
        const rate = rateOf(text);
        // The label is the row's words with its figure removed, so the report
        // reads "CGST 2.5%" rather than a column of spaces.
        const label = (text.slice(0, amountToken.index) + text.slice(amountToken.end))
          .replace(/\s{2,}/g, ' ').replace(/[\s.:|\-–—_]+$/, '').trim() || cls.kind;
        const entry = {
          kind: cls.kind,
          key: cls.key,
          label,
          amount,
          rate,
          lineIndex,
          geo: { ...geo, amountWord: wordFromEnd(line, 0) },
          raw: text.trim(),
        };
        if (cls.kind === 'tax') taxes.push(entry);
        else if (cls.kind === 'total') meta.__total = entry;
        else if (cls.kind === 'subtotal') meta.__subtotal = entry;
        else if (cls.kind === 'taxable') meta.__taxable = entry;
        else if (cls.kind === 'discount') adjustments.push(entry);
        else if (cls.kind === 'roundoff') meta.__roundOff = entry;
        else if (cls.kind === 'tendered') meta.__tendered = entry;
        else if (cls.kind === 'change') meta.__change = entry;
        return;
      }

      // plain text line — candidate item
      const item = parseItemLine(text, amountTokens, geo);
      if (item) {
        item.lineIndex = lineIndex;
        // Straighten the geometry out for stage 5: the amount is the last word
        // on the line, the unit price is the one before it.
        item.geo = { ...geo, amountWord: geo.lastWord };
        items.push(item);
      } else if (amountTokens.length === 0) {
        if (!meta.merchant && /[A-Za-z]{2,}/.test(text) && text.trim().length <= 48 && lineIndex < 6) {
          meta.merchant = text.trim().replace(/^[^A-Za-z0-9]+/, '');
        } else if (!/^[\d\s\W]*$/.test(text)) {
          misc.push({ lineIndex, text: text.trim() });
        }
      } else {
        misc.push({ lineIndex, text: text.trim(), amounts: amountTokens.map((a) => a.value) });
      }
    });

    const totals = {
      subtotal: meta.__subtotal ? meta.__subtotal.amount : null,
      taxable: meta.__taxable ? meta.__taxable.amount : null,
      discount: adjustments.filter((a) => a.kind === 'discount').reduce((s, a) => s + a.amount, 0) || null,
      tax: taxes.length ? taxes.reduce((s, t) => s + t.amount, 0) : null,
      roundOff: meta.__roundOff ? meta.__roundOff.amount : null,
      total: meta.__total ? meta.__total.amount : null,
      tendered: meta.__tendered ? meta.__tendered.amount : null,
      change: meta.__change ? meta.__change.amount : null,
    };

    const fields = {
      subtotal: meta.__subtotal || null,
      taxable: meta.__taxable || null,
      total: meta.__total || null,
      roundOff: meta.__roundOff || null,
      tendered: meta.__tendered || null,
      change: meta.__change || null,
    };

    const itemsSum = U.round2(items.reduce((s, i) => s + i.amount, 0));

    return {
      currency,
      meta,
      items,
      taxes,
      adjustments,
      totals,
      fields,
      itemsSum,
      misc,
      suspiciousText,
      counts: { lines: lines.length, items: items.length, taxes: taxes.length, adjustments: adjustments.length },
      source: (input && input.source) || 'image',
    };
  }

  RS.parse = { parse, scanAmounts, classify, maskDatesTimes, fixNumericToken };
})(window);

   ReceiptShield — validate.js
   Stage 4: mathematical validation.

   Every equation the receipt asserts is recomputed from the numbers the
   document itself prints, then compared with the printed answer. Nothing is
   taken on trust: if a document says qty × unit = line total, or that
   items − discount + tax = grand total, that claim gets checked.

   Exposes window.RS.validate
   ========================================================================== */
(function (global) {
  'use strict';

  const RS = global.RS;
  const U = RS.util;

  const PASS = 'pass', WARN = 'warn', FAIL = 'fail', SKIP = 'skip';

  /** Tolerance for a single printed line: rounding noise plus OCR jitter. */
  const lineTol = (amount) => Math.max(0.02, Math.abs(amount || 0) * 0.005);
  /** Tolerance for a sum of many lines. */
  const sumTol = (expected) => Math.max(0.5, Math.abs(expected || 0) * 0.002);

  function status(delta, tol) {
    const d = Math.abs(delta);
    if (d <= tol) return PASS;
    if (d <= tol * 3) return WARN;
    return FAIL;
  }

  function check(o) {
    return {
      stage: 'math',
      status: o.status,
      id: o.id,
      label: o.label,
      equation: o.equation,
      printed: o.printed,
      computed: o.computed,
      delta: o.delta,
      tol: o.tol,
      severity: o.severity || 'medium',
      detail: o.detail || '',
    };
  }

   * @param {object} r structured receipt from RS.parse
   * @returns {{checks:Array, summary:object, reconciles:boolean}}
   */

    const sym = r.currency.symbol;
    const m = (v) => U.fmtMoney(v, sym);
    const T = r.totals;
    const items = r.items.filter((i) => Number.isFinite(i.amount));

    /* ── 1. is there anything to check? ─────────────────────── */
    if (!items.length) {
      checks.push(check({
        id: 'items-present', label: 'Line items detected', status: FAIL, severity: 'medium',
        equation: 'at least one line item', printed: 0, computed: items.length,
        delta: NaN, tol: 0,
        detail: 'No line item with a price could be read, so the arithmetic behind this receipt cannot be verified.',
      }));
    } else {
      checks.push(check({
        id: 'items-present', label: 'Line items detected', status: PASS, severity: 'info',
        equation: 'count of priced line items', printed: items.length, computed: items.length,
        delta: 0, tol: 0, detail: items.length + ' priced line item(s) parsed.',
      }));
    }

    if (!Number.isFinite(T.total)) {
      checks.push(check({
        id: 'total-present', label: 'Grand total present', status: FAIL, severity: 'high',
        equation: 'a printed grand total', printed: NaN, computed: T.total,
        delta: NaN, tol: 0,
        detail: 'No grand total could be found. Without it there is nothing to reconcile against, which is itself unusual for a real receipt.',
      }));
    } else {
      checks.push(check({
        id: 'total-present', label: 'Grand total present', status: PASS, severity: 'info',
        equation: 'printed grand total', printed: T.total, computed: T.total,
        delta: 0, tol: 0, detail: 'Grand total read as ' + m(T.total) + '.',
      }));
    }

    /* ── 2. each line: qty × unit = line total ─────────────── */
    const lineFails = [];
    items.forEach((it, i) => {
      if (!it.qtyStated || !Number.isFinite(it.unit) || it.unitDerived) return;
      const expected = U.round2(it.qty * it.unit);
      const delta = U.round2(it.amount - expected);
      const tol = lineTol(expected);
      const st = status(delta, tol);
      if (st === PASS) return;
      const row = check({
        id: 'line-' + i, label: 'Line ' + (i + 1) + ': ' + it.name, status: st, severity: st === FAIL ? 'high' : 'medium',
        equation: it.qty + ' × ' + m(it.unit) + ' = ' + m(expected),
        printed: it.amount, computed: expected, delta, tol,
        detail: 'Printed line total ' + m(it.amount) + ' does not match ' + it.qty + ' × ' + m(it.unit) + ' (' + m(expected) + ').',
      });
      lineFails.push(row);
      checks.push(row);
    });
    checks.push(check({
      id: 'line-qty-unit', label: 'Quantity × unit price on every line',
      status: lineFails.some((c) => c.status === FAIL) ? FAIL : (lineFails.length ? WARN : PASS),
      severity: 'medium',
      equation: 'qty × unit = line total, all lines',
      printed: lineFails.length, computed: 0, delta: lineFails.length, tol: 0,
      detail: lineFails.length
        ? lineFails.length + ' line(s) fail their own multiplication.'
        : 'Every stated quantity times its unit price equals the printed line total.',
    }));

    /* ── 3. items ⇒ subtotal ───────────────────────────────── */
    const itemsSum = r.itemsSum;
    if (Number.isFinite(T.subtotal)) {
      const expected = itemsSum;
      const delta = U.round2(T.subtotal - expected);
      const tol = sumTol(expected);
      const st = status(delta, tol);
      checks.push(check({
        id: 'items-sum-subtotal', label: 'Line items add up to the subtotal',
        status: st, severity: st === FAIL ? 'critical' : 'medium',
        equation: 'Σ line totals = subtotal → ' + m(itemsSum),

        status: SKIP, severity: 'info', equation: 'Σ line totals = subtotal',
        printed: NaN, computed: itemsSum, delta: NaN, tol: 0,
        detail: 'No subtotal line printed; the sum of the items (' + m(itemsSum) + ') is carried forward instead.',

      const expected = U.round2(T.subtotal - discount);
      const delta = U.round2(T.taxable - expected);
      const tol = sumTol(expected);
      const st = status(delta, tol);
      checks.push(check({
        id: 'subtotal-less-discount', label: 'Subtotal − discount = taxable value', status: st,
        severity: st === FAIL ? 'high' : 'medium',
        equation: m(T.subtotal) + ' − ' + m(discount) + ' = ' + m(expected),
        printed: T.taxable, computed: expected, delta, tol,
        detail: st === PASS
          ? 'The taxable value ' + m(T.taxable) + ' matches subtotal minus discount.'
          : 'Taxable value should be ' + m(expected) + ' but the receipt prints ' + m(T.taxable) + '.',
      }));
    }

    /* ── 5. net + tax + round-off = grand total ────────────── */
    if (Number.isFinite(T.total)) {

        status: st, severity: st === FAIL ? 'high' : 'info',
        equation: m(T.tendered) + ' ≥ ' + m(T.total),

          : 'The amount shown as paid (' + m(T.tendered) + ') is ' + m(short) + ' short of the printed total.',

        equation: m(T.tendered) + ' − ' + m(T.total) + ' = ' + m(expected),

/* ==========================================================================
   ReceiptShield — visual.js
   Stage 5: visual tampering analysis.

   Four independent looks at the pixels and the typography:

     1. Error-level analysis (ELA) — re-compress the image and measure how much
        each pixel moves. A region pasted in after the original was saved has a
        different compression history and lights up next to the rest of the file.
     2. Paper-tone mapping — find flat background pixels and look for patches
        whose tone does not match the rest of the sheet. A paste almost always
        carries a slightly different white.
     3. Typography forensics — glyph height, character width and right-edge
        alignment of every amount-like word. A figure typed in a different face,
        at a different size, or nudged off the value column breaks the pattern.
     4. Suspicious-file check — image-editor metadata and APP segments left in
        the container.

   Exposes window.RS.visual
   ========================================================================== */
(function (global) {
  'use strict';

  const RS = global.RS;
  const U = RS.util;

  /* ── shared helpers ──────────────────────────────────────── */
  function blank(w, h) {
    const c = document.createElement('canvas');
    c.width = w; c.height = h;
    return c;
  }
  const px = (ctx, w, h) => ctx.getImageData(0, 0, w, h);

  /* ── 1. error-level analysis ─────────────────────────────── */
  async function errorLevel(canvas, quality) {
    const w = canvas.width, h = canvas.height;
    const src = canvas.getContext('2d', { willReadFrequently: true }).getImageData(0, 0, w, h);
    const a = src.data;

    const blob = await new Promise((r) => canvas.toBlob(r, 'image/jpeg', quality || 0.70));
    const bmp = await createImageBitmap(blob);
    const tmp = blank(w, h);
    const tctx = tmp.getContext('2d', { willReadFrequently: true });
    tctx.drawImage(bmp, 0, 0);
    bmp.close();
    const b = tctx.getImageData(0, 0, w, h).data;

    const ela = new Float32Array(w * h);
    for (let i = 0, p = 0; i < a.length; i += 4, p++) {
      const d0 = Math.abs(a[i] - b[i]);
      const d1 = Math.abs(a[i + 1] - b[i + 1]);
      const d2 = Math.abs(a[i + 2] - b[i + 2]);
      ela[p] = Math.max(d0, Math.max(d1, d2));
    }

    // Snap the grid to the 8×8 JPEG block lattice: cells that straddle block
    // boundaries inherit spurious residue and would read as false hot spots.
    const cell = Math.max(24, Math.round(Math.round(Math.min(w, h) / 26) / 8) * 8);
    const cols = Math.max(1, Math.ceil(w / cell));
    const rows = Math.max(1, Math.ceil(h / cell));
    const cells = [];
    for (let cy = 0; cy < rows; cy++) {
      for (let cx = 0; cx < cols; cx++) {
        const x0 = cx * cell, y0 = cy * cell;
        const x1 = Math.min(w, x0 + cell), y1 = Math.min(h, y0 + cell);
        let sum = 0, n = 0, mx = 0, dark = 0;
        for (let y = y0; y < y1; y++) {
          const base = y * w;
          for (let x = x0; x < x1; x++) {
            const v = ela[base + x];
            sum += v; n++;
            if (v > mx) mx = v;
            const i = (base + x) * 4;
            if (0.299 * a[i] + 0.587 * a[i + 1] + 0.114 * a[i + 2] < 150) dark++;
          }
        }
        cells.push({
          cx, cy, x: x0, y: y0, w: x1 - x0, h: y1 - y0,
          mean: n ? sum / n : 0, max: mx,
          ink: n ? dark / n : 0,        // how much of the cell is actually ink
        });
      }
    }

    const means = cells.map((c) => c.mean);
    const med = U.median(means);
    const spread = U.mad(means);
    const p99 = U.percentile(Array.from(ela), 99);

    // Error level rises with how much ink is in a cell, so a cell must only ever
    // be compared with cells carrying a similar amount of ink. Without this,
    // ordinary text looks anomalous next to blank paper and every receipt reads
    // as tampered — the single most common way ELA produces nonsense.
    const INK_GROUPS = [
      { id: 'blank paper', test: (c) => c.ink <= 0.005 },
      { id: 'light text', test: (c) => c.ink > 0.005 && c.ink <= 0.06 },
      { id: 'moderate text', test: (c) => c.ink > 0.06 && c.ink <= 0.18 },
      { id: 'dense text', test: (c) => c.ink > 0.18 },
    ];

    const hotspots = [];
    const groupStats = [];
    INK_GROUPS.forEach((grp) => {
      const g = cells.filter(grp.test);
      if (g.length < 8) return;
      const vals = g.map((c) => c.mean);
      const gMed = U.median(vals);
      const gSpread = Math.max(U.mad(vals), 0.35);
      let flagged = 0;
      g.forEach((c) => {
        const z = U.robustZ(c.mean, gMed, gSpread);
        if (z > 3.5 && c.mean - gMed > 0.6 && c.mean > 0.8) {
          c.z = z;
          c.group = grp.id;
          c.groupMedian = gMed;
          hotspots.push(c);
          flagged++;
        }
      });
      groupStats.push({ id: grp.id, cells: g.length, median: gMed, mad: gSpread, flagged });
    });

    const hot = hotspots;

    return {
      ela, w, h, cells, hot, groups: groupStats,
      stats: { median: med, mad: spread, p99, max: U.percentile(Array.from(ela), 100), mean: U.mean(Array.from(ela)) },
      norm: normalize(ela, p99 || 255),
    };
  }

  function normalize(ela, ceil) {
    const out = new Uint8ClampedArray(ela.length);
    const c = Math.max(1, ceil);
    for (let i = 0; i < ela.length; i++) out[i] = U.clamp((ela[i] / c) * 255, 0, 255);
    return out;
  }

  /** Group grid cells into connected blobs and return bounding boxes. */
  function groupCells(cells, w, h, minCells) {
    const map = new Map();
    cells.forEach((c) => map.set(c.cx + ',' + c.cy, c));
    const seen = new Set();
    const blobs = [];

    cells.forEach((start) => {
      const key = start.cx + ',' + start.cy;
      if (seen.has(key)) return;
      const stack = [start];
      seen.add(key);
      const members = [];
      while (stack.length) {
        const c = stack.pop();
        members.push(c);
        for (let dy = -1; dy <= 1; dy++) {
          for (let dx = -1; dx <= 1; dx++) {
            if (!dx && !dy) continue;
            const k = (c.cx + dx) + ',' + (c.cy + dy);
            if (seen.has(k) || !map.has(k)) continue;
            seen.add(k);
            stack.push(map.get(k));
          }
        }
      }
      if (members.length < (minCells || 2)) return;
      const x0 = Math.min(...members.map((c) => c.x));
      const y0 = Math.min(...members.map((c) => c.y));
      const x1 = Math.max(...members.map((c) => c.x + c.w));
      const y1 = Math.max(...members.map((c) => c.y + c.h));
      blobs.push({
        x: x0, y: y0, w: x1 - x0, h: y1 - y0,
        cells: members.length,
        members,
        strength: U.mean(members.map((c) => c.z === undefined ? 0 : c.z)),
      });
    });
    return blobs.sort((a, b) => (b.w * b.h) - (a.w * a.h));
  }

  /* ── 2. paper-tone mapping ───────────────────────────────── */
  function paperTone(canvas) {
    const w = canvas.width, h = canvas.height;
    const d = canvas.getContext('2d', { willReadFrequently: true }).getImageData(0, 0, w, h).data;
    const cell = 14;
    const cols = Math.ceil(w / cell), rows = Math.ceil(h / cell);
    const grid = [];

    for (let cy = 0; cy < rows; cy++) {
      for (let cx = 0; cx < cols; cx++) {
        const x0 = cx * cell, y0 = cy * cell;
        const x1 = Math.min(w, x0 + cell), y1 = Math.min(h, y0 + cell);
        let sum = 0, sum2 = 0, n = 0;
        for (let y = y0; y < y1; y++) {
          for (let x = x0; x < x1; x++) {
            const i = (y * w + x) * 4;
            const lum = 0.299 * d[i] + 0.587 * d[i + 1] + 0.114 * d[i + 2];
            sum += lum; sum2 += lum * lum; n++;
          }
        }
        if (!n) continue;
        const mean = sum / n;
        const sd = Math.sqrt(Math.max(0, sum2 / n - mean * mean));
        grid.push({ cx, cy, x: x0, y: y0, w: x1 - x0, h: y1 - y0, mean, sd });
      }
    }

    // only pixels that look like blank paper can define the paper tone
    const flat = grid.filter((c) => c.sd < 9 && c.mean > 140);
    const tone = U.median(flat.map((c) => c.mean));
    const spread = U.mad(flat.map((c) => c.mean));

    const off = flat.filter((c) => Math.abs(c.mean - tone) >= Math.max(4, spread * 4));
    const blobs = groupCells(off.map((c) => ({ ...c })), w, h, 4);

    return {
      tone,
      spread,
      flatCells: flat.length,
      offCells: off.length,
      regions: blobs.map((b) => ({
        ...b,
        delta: (() => {
          const inside = flat.filter((c) => c.x >= b.x && c.x < b.x + b.w && c.y >= b.y && c.y < b.y + b.h);
          return inside.length ? U.mean(inside.map((c) => c.mean)) - tone : 0;
        })(),
      })),
    };
  }

  /* ── 3. typography forensics ─────────────────────────────── */
  function typography(ocr, receipt) {
    // Only amounts the parser actually treated as money take part. Text that is
    // amount-shaped but not money — a postal code, a registration number — would
    // otherwise be compared against a currency column it never belonged to.
    const metrics = [];
    const seen = new Set();
    const add = (w) => {
      if (!w || !w.text) return;
      const key = Math.round(w.x0) + ':' + Math.round(w.y0) + ':' + w.text;
      if (seen.has(key)) return;
      seen.add(key);
      const h = w.y1 - w.y0;
      const cw = (w.x1 - w.x0) / Math.max(1, w.text.length);
      if (h < 5 || cw <= 0) return;
      metrics.push({ text: w.text, conf: w.conf, x0: w.x0, x1: w.x1, y0: w.y0, y1: w.y1, h, cw, right: w.x1 });
    };

    receipt.items.forEach((i) => {
      if (!i.geo) return;
      if (i.unitStated) add(i.geo.unitWord);
      add(i.geo.amountWord);
    });
    ['subtotal', 'taxable', 'total', 'roundOff', 'tendered', 'change'].forEach((k) => {
      const f = receipt.fields[k];
      if (f && f.geo) add(f.geo.amountWord);
    });
    receipt.taxes.forEach((t) => add(t.geo && t.geo.amountWord));
    receipt.adjustments.forEach((a) => add(a.geo && a.geo.amountWord));

    if (metrics.length < 4) {
      return { enough: false, amountWords: metrics.length, outliers: [], columns: [], regions: [] };
    }

    // A receipt has several money columns (unit price, line total, grand total).
    // They must be compared against themselves, not against each other, so first
    // group the amounts by right edge. Single linkage with a tolerance a little
    // wider than typical OCR jitter keeps one column together while a figure
    // nudged off it still lands inside its own column and can be measured.
    const tol = Math.max(8, canvasIndependentTol(metrics));
    const columns = clusterByRight(metrics, tol).filter((c) => c.items.length >= 3);

    const outliers = [];
    const summary = [];
    columns.forEach((col) => {
      const ms = col.items;
      const medH = U.median(ms.map((m) => m.h));
      const madH = U.mad(ms.map((m) => m.h));
      const medW = U.median(ms.map((m) => m.cw));
      const madW = U.mad(ms.map((m) => m.cw));
      const medR = U.median(ms.map((m) => m.right));
      const madR = U.mad(ms.map((m) => m.right));
      summary.push({ right: medR, size: ms.length, height: medH, charWidth: medW, madRight: madR });

      ms.forEach((m) => {
        const zH = U.robustZ(m.h, medH, madH);
        const zW = U.robustZ(m.cw, medW, madW);
        const ratioH = m.h / medH;
        const ratioW = m.cw / medW;
        const align = m.right - medR;

        const sizeBad = Math.abs(zH) > 3.5 && (ratioH > 1.16 || ratioH < 0.86);
        const widthBad = Math.abs(zW) > 3.5 && (ratioW > 1.12 || ratioW < 0.89);
        const alignBad = Math.abs(align) > Math.max(3, madR * 4);

        // Glyph height is the reliable measurement; OCR word boxes wobble by a few
        // pixels horizontally, so a lone width or a lone small alignment deviation
        // is not enough to accuse an amount of being retyped. Two weak signals, or
        // one strong one, is the bar.
        const flagged =
          sizeBad ||
          (widthBad && alignBad) ||
          (alignBad && Math.abs(align) > 10) ||
          (widthBad && ratioW > 1.4);
        if (!flagged) return;

        outliers.push({
          text: m.text,
          x: m.x0, y: m.y0, w: m.x1 - m.x0, h: m.h,
          column: Math.round(medR),
          reasons: [
            sizeBad ? 'glyph height ' + (ratioH * 100).toFixed(0) + '% of its column’s median' : null,
            widthBad ? 'character width ' + (ratioW * 100).toFixed(0) + '% of its column’s median' : null,
            alignBad ? 'right edge ' + (align > 0 ? '+' : '') + align.toFixed(1) + 'px off the column' : null,
          ].filter(Boolean),
          zH, zW, align,
          weight: (sizeBad ? 0.42 : 0) + (widthBad ? 0.44 : 0) + (alignBad ? 0.3 : 0),
        });
      });
    });

    return {
      enough: true,
      amountWords: metrics.length,
      columns: summary,
      median: summary[0] || { height: U.median(metrics.map((m) => m.h)), charWidth: U.median(metrics.map((m) => m.cw)) },
      outliers,
      regions: outliers.map((o) => ({
        x: Math.max(0, o.x - 6), y: Math.max(0, o.y - 6), w: o.w + 12, h: o.h + 12,
        cells: 1, score: U.clamp(o.weight, 0, 1), label: 'typography',
        why: o.text + ' — ' + o.reasons.join('; '),
      })),
    };
  }

  /** Group amounts by right edge with single-linkage clustering. */
  function clusterByRight(metrics, tol) {
    const sorted = metrics.slice().sort((a, b) => a.right - b.right);
    const clusters = [];
    sorted.forEach((m) => {
      const last = clusters[clusters.length - 1];
      if (last && m.right - last.max <= tol) {
        last.items.push(m);
        last.max = Math.max(last.max, m.right);
      } else {
        clusters.push({ items: [m], max: m.right });
      }
    });
    return clusters;
  }

  /**
   * Column tolerance, derived from the amount metrics themselves rather than
   * from the image size, so it works for a phone snap and a flatbed scan alike.
   */
  function canvasIndependentTol(metrics) {
    const chars = metrics.map((m) => m.cw).filter(Number.isFinite).sort((a, b) => a - b);
    const med = chars.length ? chars[chars.length >> 1] : 10;
    return med * 0.9;
  }

  /* ── 4. suspicious-file check ────────────────────────────── */
  const EDITOR_TAGS = [
    'Adobe Photoshop', 'Adobe Lightroom', 'Adobe Illustrator', 'Photoshop',
    'GIMP', 'Canva', 'Pixlr', 'Photopea', 'Snapseed', 'Picsart', 'Fotor',
    'Paint.NET', 'IrfanView', 'XnView', 'Affinity Photo', 'Capture One',
    'AcdSee', 'CorelDRAW', 'Sketch', 'Meitu', 'Aviary', 'inPixio', 'Movavi',
  ];

  async function fileCheck(blob) {
    const out = { available: !!blob, isJpeg: false, editorTags: [], software: null, appSegments: 0, size: 0 };
    if (!blob || typeof blob.slice !== 'function') return out;
    out.size = blob.size;
    const head = await blob.slice(0, 384 * 1024).arrayBuffer();
    const bytes = new Uint8Array(head);

    if (bytes.length > 3 && bytes[0] === 0xff && bytes[1] === 0xd8) out.isJpeg = true;

    // count JPEG APP segments
    if (out.isJpeg) {
      let i = 2;
      while (i + 4 < bytes.length && bytes[i] === 0xff) {
        const marker = bytes[i + 1];
        if (marker === 0xda || marker === 0xd9) break;
        const len = (bytes[i + 2] << 8) | bytes[i + 3];
        if (marker >= 0xe0 && marker <= 0xef) out.appSegments++;
        if (len < 2) break;
        i += 2 + len;
      }
    }

    const ascii = new TextDecoder('latin1').decode(bytes);
    EDITOR_TAGS.forEach((tag) => {
      if (ascii.indexOf(tag) !== -1 && out.editorTags.indexOf(tag) === -1) out.editorTags.push(tag);
    });
    const sw = ascii.match(/<xmp:CreatorTool>([^<]{1,80})<\/xmp:CreatorTool>/i)
      || ascii.match(/xmp:CreatorTool="([^"]{1,80})"/i)
      || ascii.match(/Software["']?\s*[:=]\s*["']?([^"'\r\n]{1,60})/i);
    if (sw) out.software = sw[1].trim();
    return out;
  }

  /* ── combine ─────────────────────────────────────────────── */
  function mergeRegions(candidates) {
    const merged = [];
    candidates.filter(Boolean).forEach((c) => {
      const found = merged.find((m) => U.overlapRatio(m, c) > 0.28 || contains(m, c));
      if (found) {
        found.signals.push(c);
        found.x = Math.min(found.x, c.x);
        found.y = Math.min(found.y, c.y);
        found.x1 = Math.max(found.x1, c.x + c.w);
        found.y1 = Math.max(found.y1, c.y + c.h);
        found.w = found.x1 - found.x;
        found.h = found.y1 - found.y;
      } else {
        merged.push({ x: c.x, y: c.y, x1: c.x + c.w, y1: c.y + c.h, w: c.w, h: c.h, signals: [c] });
      }
    });
    merged.forEach((m) => {
      const kinds = {};
      m.signals.forEach((s) => { kinds[s.label] = (kinds[s.label] || 0) + 1; });
      m.kinds = Object.keys(kinds);
      m.score = U.clamp(m.signals.reduce((s, x) => s + (x.score || 0.3), 0), 0, 1);
      m.why = Array.from(new Set(m.signals.map((s) => s.why).filter(Boolean))).slice(0, 4);
    });
    return merged.sort((a, b) => b.score - a.score || (b.w * b.h) - (a.w * a.h));
  }
  const contains = (a, b) =>
    a.x <= b.x && a.y <= b.y && (a.x1 !== undefined ? a.x1 : a.x + a.w) >= b.x + b.w && a.y1 >= b.y + b.h;

  /* ── main ────────────────────────────────────────────────── */
  /**
   * @param {HTMLCanvasElement} canvas  the receipt at natural resolution
   * @param {object} receipt            RS.parse output
   * @param {object} ocr                RS.ocr output
   * @param {Blob}   blob               the original file, for the container check
   */
  async function analyze(canvas, receipt, ocr, blob) {
    const findings = [];
    const checks = [];
    const note = [];

    const ela = await errorLevel(canvas, 0.70);
    const tone = paperTone(canvas);
    const typo = typography(ocr, receipt);
    const file = await fileCheck(blob);

    /* 1 — error level */
    const elaBlobs = groupCells(ela.hot, canvas.width, canvas.height, 4).map((b) => {
      const members = b.members || [];
      const groups = Array.from(new Set(members.map((m) => m.group)));
      const zs = members.map((m) => m.z).filter(Number.isFinite);
      const meanZ = zs.length ? U.mean(zs) : 0;
      const strongest = members.reduce((a, b2) => (b2.z > a.z ? b2 : a), members[0] || { z: 0 });
      return {
        x: b.x, y: b.y, w: b.w, h: b.h, cells: members.length, label: 're-compression',
        strong: members.length >= 6 || meanZ >= 5,
        score: U.clamp(0.45 + members.length / 50 + Math.min(meanZ, 12) / 40, 0, 1),
        why: members.length + ' adjacent cells of ' + (groups.join(' / ') || 'similar') +
          ' carry more re-compression residue than that content normally does here (error level ' +
          (strongest.mean || 0).toFixed(1) + ' against ' + (strongest.groupMedian || 0).toFixed(1) + ' typical)',
      };
    });
    const elaAll = elaBlobs;
    const strongEla = elaAll.filter((b) => b.strong);

    const groupLine = (ela.groups || [])
      .map((g) => g.id + ' ' + g.cells + ' cells, ' + g.flagged + ' flagged')
      .join(' · ');
    checks.push({
      stage: 'visual',
      status: strongEla.length ? 'fail' : (elaAll.length ? 'warn' : 'pass'),
      label: 'Error-level analysis', id: 'ela',
      detail: (elaAll.length
        ? strongEla.length + ' of ' + elaAll.length + ' region(s) show re-compression residue well above what the same kind of content shows elsewhere in this file.'
        : 'Re-compression residue is consistent with the content of each region; nothing stands out.') +
        (groupLine ? ' Comparisons were made within ink-coverage bands: ' + groupLine + '.' : ''),
    });
    note.push('Error level compares each region only against other regions carrying a similar amount of ink, so ordinary text is never mistaken for tampering.');

    /* 2 — paper tone */
    const toneRegions = tone.regions.map((r) => ({
      x: r.x, y: r.y, w: r.w, h: r.h, cells: r.cells, label: 'tone mismatch',
      score: U.clamp(0.35 + Math.abs(r.delta) / 30, 0, 1),
      why: 'blank paper here reads ' + (r.delta > 0 ? '+' : '') + r.delta.toFixed(1) +
        ' luminance away from the sheet average (' + tone.tone.toFixed(0) + ') across ' + r.cells + ' patches',
    }));

    checks.push({
      stage: 'visual', status: toneRegions.length ? 'fail' : 'pass',
      label: 'Paper-tone consistency', id: 'tone',
      detail: toneRegions.length
        ? toneRegions.length + ' patch(es) of blank paper do not match the sheet’s baseline tone of ' +
          tone.tone.toFixed(0) + ' — consistent with content pasted from a different image.'
        : 'Every blank area of the sheet shares one paper tone (' + tone.tone.toFixed(0) + ' ± ' + tone.spread.toFixed(2) + ').',
    });

    /* 3 — typography */
    const typoRegions = typo.enough ? typo.regions.map((r) => ({ ...r, points: r.score })) : [];
    checks.push({
      stage: 'visual',
      status: !typo.enough ? 'skip' : (typo.outliers.length ? 'fail' : 'pass'),
      label: 'Amount typography consistency', id: 'typo',
      detail: !typo.enough
        ? 'Not enough amount-like words were recognised to compare glyph metrics.'
        : typo.outliers.length
          ? typo.outliers.length + ' amount(s) break the value column’s type pattern: ' +
            typo.outliers.map((o) => o.text + ' (' + o.reasons.join(', ') + ')').join(' · ')
          : 'All ' + typo.amountWords + ' amounts share the column’s glyph height, character width and right edge.',
    });

    /* 4 — container */
    const editorHit = file.editorTags.length > 0 || !!file.software;
    checks.push({
      stage: 'visual',
      status: editorHit ? 'fail' : 'pass',
      label: 'Suspicious file metadata', id: 'filemeta',
      detail: editorHit
        ? 'The file container names an image editor: ' + (file.software || file.editorTags.join(', ')) +
          (file.isJpeg ? ' (JPEG, ' + file.appSegments + ' APP segment(s))' : '') + '.'
        : file.available
          ? 'No image-editor signature found in the file container' + (file.isJpeg ? ' (JPEG, ' + file.appSegments + ' APP segment(s))' : '') + '.'
          : 'Container analysis not available for this input.',
    });

    /* 5 — confidence clusters (supporting evidence only) */
    const lowConf = (ocr.words || []).filter((w) => w.conf < 55 && w.text.trim().length > 1);
    const docConf = ocr.conf || 0;
    let confRegions = [];
    if (lowConf.length && docConf > 70) {
      const blobs = groupCells(
        lowConf.map((w) => ({
          cx: Math.round(w.x0 / 40), cy: Math.round(w.y0 / 18),
          x: Math.round(w.x0), y: Math.round(w.y0),
          w: Math.round(w.x1 - w.x0), h: Math.round(w.y1 - w.y0),
        })),
        canvas.width, canvas.height, 2
      );
      confRegions = blobs.map((b) => ({
        x: b.x, y: b.y, w: b.w, h: b.h, cells: b.cells, label: 'low confidence',
        score: 0.22,
        why: b.cells + ' low-confidence word(s) clustered together while the document averages ' + docConf.toFixed(0) + '% confidence',
      }));
    }

    /* merge everything the image stage found */
    const regions = mergeRegions([...elaAll, ...toneRegions, ...typoRegions, ...confRegions]);
    regions.forEach((r, i) => {
      r.index = i + 1;
      r.kinds = r.kinds || [];
      if (!r.why.length) r.why = ['region flagged by the image stage'];
    });

    /* findings */
    if (toneRegions.length) findings.push({
      stage: 'visual', id: 'tone-patch', severity: 'high',
      title: 'Background patch does not match the paper',
      detail: 'One or more blank areas of the sheet have a different paper tone from the rest of the image. When content is copied from another file, the surrounding background usually comes with it.',
      evidence: toneRegions.map((r) => 'at (' + r.x + ',' + r.y + ') ' + r.w + '×' + r.h + ': ' + r.why).join('\n'),
      region: toneRegions[0],
    });
    if (elaAll.length) findings.push({
      stage: 'visual', id: 'ela', severity: strongEla.length ? 'high' : 'low',
      title: 'Re-compression residue outlines edited regions',
      detail: 'Error-level analysis highlights where the file’s compression history is inconsistent. Content added after the original was saved has been through fewer compression cycles than the rest of the sheet.',
      evidence: elaAll.slice(0, 4).map((r) => 'at (' + r.x + ',' + r.y + ') ' + r.w + '×' + r.h + ': ' + r.why).join('\n'),
      region: elaAll[0],
    });
    if (typo.enough && typo.outliers.length) findings.push({
      stage: 'visual', id: 'typo', severity: 'high',
      title: 'Amounts break the value column’s type pattern',
      detail: 'Glyph height, character width and right-edge alignment are compared across every amount on the receipt. Words typed in another face, at another size, or nudged off the column stand out.',
      evidence: typo.outliers.map((o) => '“' + o.text + '” — ' + o.reasons.join('; ')).join('\n'),
      region: typoRegions[0],
    });
    if (editorHit) findings.push({
      stage: 'visual', id: 'filemeta', severity: 'medium',
      title: 'File carries image-editor metadata',
      detail: 'The container names an image editor and/or an XMP creator tool. That is normal for a legitimately exported or resized receipt, but it also means the pixels have been through an editor at least once.',
      evidence: (file.software ? 'CreatorTool: ' + file.software + '\n' : '') +
        (file.editorTags.length ? 'Matched in file bytes: ' + file.editorTags.join(', ') : ''),
      region: null,
    });
    if (confRegions.length) findings.push({
      stage: 'visual', id: 'lowconf', severity: 'low',
      title: 'Clustered low-confidence characters',
      detail: 'A group of characters was read with much lower confidence than the rest of the document. Pasted text that was never part of the original render often scans less cleanly. This is supporting evidence only.',
      evidence: confRegions.map((r) => 'at (' + r.x + ',' + r.y + ') ' + r.why).join('\n'),
      region: confRegions[0],
    });

    // Repoint every finding at the merged region it actually lives in, so the
    // report can link straight from a written finding to the picture.
    findings.forEach((f) => {
      if (!f.region) return;
      const hit = regions.find((r) => U.overlapRatio(r, f.region) > 0.2 || contains(r, f.region));
      if (hit) f.region = hit;
    });

    return {
      ela, tone, typo, file,
      checks,
      findings,
      regions: regions.slice(0, 14),
      note: note.join(' '),
      ok: true,
    };
  }

  /* ── rendering ───────────────────────────────────────────── */
  const HEAT_LUT = (() => {
    const lut = new Uint8ClampedArray(256 * 3);
    for (let i = 0; i < 256; i++) {
      const t = i / 255;
      lut[i * 3] = Math.round(U.clamp(t < 0.5 ? t * 2 * 90 : 255, 0, 255));
      lut[i * 3 + 1] = Math.round(U.clamp(t < 0.5 ? t * 2 * 40 : 120 + (t - 0.5) * 2 * 20, 0, 255));
      lut[i * 3 + 2] = Math.round(U.clamp(40 * (1 - t), 0, 255));
    }
    return lut;
  })();

  function renderHeat(target, norm, w, h, amplify) {
    target.width = w; target.height = h;
    const ctx = target.getContext('2d');
    const img = ctx.createImageData(w, h);
    const d = img.data;
    const amp = amplify || 1;
    for (let i = 0, p = 0; i < norm.length; i++, p += 4) {
      const v = U.clamp(norm[i] * amp, 0, 255) | 0;
      const k = v * 3;
      d[p] = HEAT_LUT[k]; d[p + 1] = HEAT_LUT[k + 1]; d[p + 2] = HEAT_LUT[k + 2]; d[p + 3] = 255;
    }
    ctx.putImageData(img, 0, 0);
  }

  function drawOverlay(target, opts) {
    const { image, regions, words, showRegions, showHeat, showText, heat, amplify } = opts;
    const w = image.width, h = image.height;
    target.width = w; target.height = h;
    const ctx = target.getContext('2d');
    ctx.drawImage(image, 0, 0);

    if (showHeat && heat) {
      const layer = blank(w, h);
      renderHeat(layer, heat, w, h, amplify ? 8 : 1);
      ctx.globalAlpha = 0.45;
      ctx.globalCompositeOperation = 'screen';
      ctx.drawImage(layer, 0, 0);
      ctx.globalCompositeOperation = 'source-over';
      ctx.globalAlpha = 1;
    }

    if (showText && words && words.length) {
      ctx.lineWidth = 1;
      words.forEach((wd) => {
        const c = wd.conf >= 80 ? 'rgba(61,220,132,.45)' : (wd.conf >= 55 ? 'rgba(245,165,36,.5)' : 'rgba(244,83,106,.6)');
        ctx.strokeStyle = c;
        ctx.strokeRect(wd.x0 + 0.5, wd.y0 + 0.5, wd.x1 - wd.x0 - 1, wd.y1 - wd.y0 - 1);
      });
    }

    if (showRegions && regions && regions.length) {
      const scale = Math.max(1.5, w / 700);
      regions.forEach((r) => {
        const hot = r.score >= 0.55;
        ctx.lineWidth = 2 * scale;
        ctx.strokeStyle = hot ? 'rgba(255,45,85,.95)' : 'rgba(245,165,36,.95)';
        ctx.strokeRect(r.x, r.y, r.w, r.h);

   ReceiptShield — report.js
   Stages 6 and 7: suspicious information detection, then the fraud risk report.

   Stage 6 looks for anomalies that are neither pure arithmetic nor pure pixels:
   repeated lines, figures whose discrepancy is an exactly round amount, a
   missing tax line, absent transaction identifiers, a grand total below one of
   its own line items.

   Stage 7 weights everything into a 0–100 score, writes a plain-language
   verdict, and assembles one report object the UI and the JSON export share.

   * noise — it is the shape of a hand-typed edit.

  function roundUnit(delta) {
    const a = Math.abs(delta);
    if (!Number.isFinite(a) || a < 40) return null;
    for (const unit of [10000, 5000, 1000, 500, 100, 50]) {
      if (Math.abs(a % unit) < 0.02 || Math.abs((a % unit) - unit) < 0.02) return unit;
    }

    $('#btnRun').disabled = !ready;
  }

  /* ── samples ─────────────────────────────────────────────── */
  async function loadSample(kind) {
    hideBanner();
    const btn = kind === 'tampered' ? $('#btnTampered') : $('#btnGenuine');
    const label = btn.textContent;
    btn.disabled = true;
    btn.textContent = 'Generating…';
    try {
      const s = await RS.samples.build(kind);
      setFile(s.blob, s.name, s.truth.note);
      showBanner('ok', 'Loaded the <strong>' + kind + '</strong> sample. Press <strong>Run detection</strong> to analyse it.');
    } catch (err) {
      console.error(err);
      showBanner('err', 'Could not generate the sample: ' + esc(err.message || String(err)));
    } finally {
      btn.disabled = false;
      btn.textContent = label;
    }
  }

  /* ── the pipeline ────────────────────────────────────────── */
  async function run() {
    if (state.running) return;
    state.running = true;
    $('#btnRun').disabled = true;
    $('#results').hidden = true;
    hideBanner();
    resetStages();
    setTag('running', 'is-run');
    live('Analysis started');

    try {
      const report = state.mode === 'image' ? await runImage() : await runText();
      paint(report);
      finishBanner(report);
      setTag('complete', 'is-done');
      live('Analysis complete. Risk score ' + report.risk.risk + ' of 100, ' + report.risk.band + '.');
    } catch (err) {
      console.error(err);
      const active = $('#stages li.is-active');
      if (active) active.className = 'is-fail';
      showBanner('err', '<strong>Analysis stopped.</strong> ' + esc(err.message || String(err)));
      setTag('failed', 'is-fail');
      live('Analysis stopped: ' + (err.message || String(err)));
    } finally {
      state.running = false;
      $('#ocrbar').hidden = true;
      $('#btnRun').disabled = false;
      $('#btnReset').hidden = false;
    }
  }

  async function runImage() {
    const src = state.file;

    /* 1 — upload */
    setStage('upload', 'active', 'Decoding the image…');
    const canvas = await blobToCanvas(src.blob);
    state.canvas = canvas;
    if (canvas.width < 200 || canvas.height < 120) {
      throw new Error('That image is too small to analyse (' + canvas.width + '×' + canvas.height + '). Receipts need at least a few hundred pixels of width.');
    }
    setStage('upload', 'done', canvas.width + ' × ' + canvas.height + ' px · ' + esc(src.type));
    live('Receipt loaded');

    /* 2 — OCR */
    setStage('ocr', 'active', 'Starting the OCR engine…');
    $('#ocrbar').hidden = false;
    updateOcr({ phase: 'Starting the OCR engine…', progress: 0 });
    state.ocr = await RS.ocr.recognize(canvas, (p) => {
      updateOcr(p);
      setStage('ocr', 'active', p.phase + ' — ' + Math.round((p.progress || 0) * 100) + '%');
    });
    $('#ocrbar').hidden = true;

    if (state.ocr.empty) {
      setStage('ocr', 'fail', 'No readable text found');
      throw new Error('No text could be read from this image. Try a sharper photo, more contrast, or paste the receipt text instead.');
    }
    setStage('ocr', 'done', state.ocr.words.length + ' words · ' + Math.round(state.ocr.conf) + '% confidence');
    live('OCR finished');

    return await finishStages(state.ocr.text, state.ocr.lines, 'image', src.blob);
  }

  async function runText() {
    const text = $('#textInput').value;
    setStage('upload', 'skip', 'Skipped — text was pasted directly');
    setStage('ocr', 'skip', 'Skipped — no image to read');
    state.canvas = null;
    state.ocr = null;
    live('Using pasted text');
    return await finishStages(text, null, 'text', null);
  }

  async function finishStages(text, lines, source, blob) {
    /* 3 — parse */
    setStage('parse', 'active', 'Classifying lines…');
    await U.sleep(30);
    const receipt = RS.parse.parse({ text, lines, source });
    state.receipt = receipt;
    setStage('parse', 'done',
      receipt.counts.items + ' item(s), ' + receipt.taxes.length + ' tax row(s), ' + receipt.adjustments.length + ' adjustment(s)');
    live('Receipt parsed');

    /* 4 — maths */
    setStage('math', 'active', 'Recomputing every equation…');
    await U.sleep(30);
    const math = RS.validate.validate(receipt);
    state.math = math;
    setStage('math', math.summary.fail ? 'warn' : 'done',
      math.summary.pass + ' passed · ' + math.summary.warn + ' warning(s) · ' + math.summary.fail + ' failed');
    live('Arithmetic validated');

    /* 5 — visual */
    let visual;
    if (source === 'image') {
      setStage('visual', 'active', 'Running error-level analysis…');
      await U.sleep(30);
      visual = await RS.visual.analyze(state.canvas, receipt, state.ocr, blob);
      visual.ran = true;
      state.visual = visual;
      setStage('visual', visual.regions.length ? 'warn' : 'done',
        visual.regions.length + ' suspicious region(s) · ' + visual.typo.amountWords + ' amounts compared');
      live('Image forensics done');
    } else {
      visual = {
        ran: false,
        checks: [{
          stage: 'visual', status: 'skip', label: 'Visual Tampering Analysis', id: 'skipped',
          detail: 'No image was supplied. Stages 1 and 5 need a picture of the receipt to work on.',
        }],
        findings: [], regions: [], note: '', file: null, ela: null, tone: null, typo: { amountWords: 0 },
      };
      state.visual = visual;
      setStage('visual', 'skip', 'Skipped — no image supplied');
    }

    /* 6 — suspicious information */
    setStage('suspicious', 'active', 'Looking for logical anomalies…');
    await U.sleep(30);
    const suspicious = RS.report.detectSuspicious(receipt, math);
    state.suspicious = suspicious;
    const suspiciousBad = suspicious.checks.filter((c) => c.status === 'fail' || c.status === 'warn').length;
    setStage('suspicious', suspiciousBad ? 'warn' : 'done',
      suspiciousBad ? suspiciousBad + ' anomaly signal(s)' : 'no anomalies found');
    live('Anomaly scan done');

    /* 7 — report */
    setStage('report', 'active', 'Weighting findings…');
    await U.sleep(30);
    const report = RS.report.build({
      receipt, math, visual, suspicious,
      ocr: state.ocr,
      meta: { ranVisual: source === 'image', source },
    });
    state.report = report;
    setStage('report', report.risk.risk >= 45 ? 'warn' : 'done',
      report.risk.risk + '/100 · ' + report.risk.band);
    return report;
  }

  function finishBanner(report) {
    const s = report.summary;
    if (s.ranVisual && s.ocrConfidence !== null && s.ocrConfidence < 60) {
      showBanner('warn',
        '<strong>Low OCR confidence (' + s.ocrConfidence + '%).</strong> Some figures may have been misread, which can create false positives in the arithmetic stage. Treat the extracts below as approximate, or retry with a sharper image.');
    } else if (!s.ranVisual) {
      showBanner('warn',
        '<strong>Text-mode run.</strong> Stages 3, 4, 6 and 7 ran against the pasted text. Visual tampering analysis needs a receipt image.');
    } else {
      showBanner('ok',
        '<strong>Analysis complete.</strong> ' + s.items + ' line item(s) extracted at ' + s.ocrConfidence +
        '% OCR confidence · ' + s.checksPassed + ' of ' + s.checksTotal + ' checks passed · ' +
        s.findings + ' finding(s) across ' + (report.risk.counts.critical + report.risk.counts.high + report.risk.counts.medium + report.risk.counts.low) + ' flagged.');
    }
  }

  /* ── painting ────────────────────────────────────────────── */
  function paint(report) {
    $('#results').hidden = false;
    $('#reportSubtitle').innerHTML =
      'Source: <strong>' + esc(state.mode === 'image' ? (state.file && state.file.name || 'image') : 'pasted text') +
      '</strong> · generated ' + new Date(report.generatedAt).toLocaleString() +
      ' · the entire analysis ran on this device.';

    renderRisk(report);
    renderTiles(report);
    renderFindings();
    renderExtraction(report);
    renderMath(report);
    renderJson(report);
    renderVisual(report);
    $$('.tab').forEach((t) => t.classList.toggle('is-active', t.dataset.tab === 'findings'));
    $$('.tabpanel').forEach((p) => p.classList.toggle('is-active', p.dataset.panel === 'findings'));
    $('#results').scrollIntoView({ behavior: 'smooth', block: 'start' });
  }

  function renderRisk(report) {
    const r = report.risk;
    $('#riskScore').textContent = r.risk;
    const dv = $('#dialValue');
    dv.style.strokeDasharray = DIAL_C;
    dv.style.strokeDashoffset = DIAL_C;
    requestAnimationFrame(() => {
      dv.style.stroke = TONE_COLOR[r.tone];
      dv.style.strokeDashoffset = DIAL_C * (1 - r.risk / 100);
    });
    const band = $('#riskBand');
    band.textContent = r.band;
    band.style.color = TONE_COLOR[r.tone];
    $('#riskVerdict').textContent = report.verdict;

    const labels = { critical: 'Critical', high: 'High', medium: 'Medium', low: 'Low', info: 'Passed' };
    $('#riskCounts').innerHTML = ['critical', 'high', 'medium', 'low', 'info']
      .filter((k) => r.counts[k])
      .map((k) => '<li><span class="dot dot--' + k + '"></span>' + labels[k] + ' <b>' + r.counts[k] + '</b></li>')
      .join('') || '<li class="muted">No findings</li>';
  }

  function renderTiles(report) {
    const s = report.summary;
    const set = (id, html) => { $('#' + id).innerHTML = html; };
    set('tileConf', s.ocrConfidence === null ? '<span class="muted">n/a</span>' : s.ocrConfidence + '<small>%</small>');
    set('tileLines', s.linesRead || '<span class="muted">—</span>');
    set('tileItems', s.items);
    set('tileChecks', s.checksPassed + '<small>/' + s.checksTotal + '</small>');
    set('tileFlags', s.findings);
    set('tileStages', (s.ranVisual ? 7 : 6) + '<small>/7</small>');
  }

  function renderFindings() {
    const report = state.report;
    if (!report) return;
    const filter = state.filter;
    const list = report.findings.filter((f) => filter === 'all' || f.severity === filter);
    const host = $('#findingsList');

    if (!list.length) {
      host.innerHTML = '<div class="empty">' +
        (filter === 'all'
          ? 'No findings at all — the arithmetic reconciles and the image stage found nothing inconsistent.'
          : 'No findings in this severity band.') + '</div>';
      return;
    }

    host.innerHTML = list.map((f) => {
      const region = f.region
        ? '<button class="linkish" data-region="' + f.region + '">Evidence region #' + f.region + ' in the visual viewer →</button>'
        : '';
      return '<article class="finding finding--' + f.severity + '">' +
        '<div class="finding__top">' +
          '<span class="finding__sev sev-' + f.severity + '">' + RS.report.SEV_LABEL[f.severity] + '</span>' +
          '<span class="finding__stage">Stage ' + (STAGE_NUM[f.stage] || '--') + ' · ' + esc(RS.report.STAGE_LABEL[f.stage] || f.stage) + '</span>' +
        '</div>' +
        '<h4>' + esc(f.title) + '</h4>' +
        '<p>' + esc(f.detail) + '</p>' +
        (f.evidence ? '<pre class="finding__ev">' + esc(f.evidence) + '</pre>' : '') +
        (region ? '<p class="finding__where">' + region + '</p>' : '') +
        '</article>';
    }).join('');
  }

  function renderExtraction(report) {
    const r = report.receipt;
    const sym = r.currency.symbol;

    $('#tblItems tbody').innerHTML = r.items.length
      ? r.items.map((i, n) => '<tr>' +
          '<td class="num">' + (n + 1) + '</td>' +
          '<td class="desc">' + esc(i.name) + '</td>' +
          '<td class="num">' + (i.qtyStated ? i.qty : '<span class="muted">' + i.qty + '*</span>') + '</td>' +
          '<td class="num">' + (i.unitDerived
            ? '<span class="muted" title="Derived from the line total ÷ quantity">' + U.fmtMoney(i.unit, sym) + '</span>'
            : U.fmtMoney(i.unit, sym)) + '</td>' +
          '<td class="num">' + U.fmtMoney(i.amount, sym) + '</td>' +
          '<td class="num">' + (i.confidence === null ? '<span class="muted">—</span>' :
            '<span class="' + (i.confidence >= 80 ? 'pos' : i.confidence >= 55 ? '' : 'neg') + '">' + i.confidence + '</span>') + '</td>' +
        '</tr>').join('')
      : '<tr><td colspan="6" class="muted">No priced line items could be extracted.</td></tr>';

    const row = (k, v, cls) => '<dt>' + esc(k) + '</dt><dd' + (cls ? ' class="' + cls + '"' : '') + '>' + v + '</dd>';
    let html = '';
    html += row('Merchant', esc(r.merchant || '—'));
    html += row('Invoice no.', esc(r.invoiceNo || '—'));
    html += row('Date', esc([r.date, r.time].filter(Boolean).join(' ') || '—'));
    html += row('GSTIN / tax id', esc(r.gstin || '—'));
    html += row('Currency detected', r.currency.code ? esc(r.currency.code + ' ' + r.currency.symbol) : '—');
    html += row('Items total (Σ lines)', U.fmtMoney(r.itemsSum, sym));
    if (Number.isFinite(r.totals.subtotal)) html += row('Printed subtotal', U.fmtMoney(r.totals.subtotal, sym));
    if (Number.isFinite(r.totals.discount)) html += row('Discount', U.fmtMoney(r.totals.discount, sym));
    if (Number.isFinite(r.totals.taxable)) html += row('Taxable value', U.fmtMoney(r.totals.taxable, sym));
    r.taxes.forEach((t) => { html += row(t.label.replace(/\s+/g, ' '), U.fmtMoney(t.amount, sym)); });
    if (Number.isFinite(r.totals.roundOff)) html += row('Rounding', U.fmtMoney(r.totals.roundOff, sym));
    html += row('<strong>Printed grand total</strong>', '<strong>' + U.fmtMoney(r.totals.total, sym) + '</strong>');
    if (report.math.computedTotal !== null) {
      const diff = U.round2(r.totals.total - report.math.computedTotal);
      html += row('Total from the receipt’s own figures', U.fmtMoney(report.math.computedTotal, sym));
      html += row('Difference', '<span class="' + (Math.abs(diff) < 0.02 ? 'pos' : 'neg') + '">' + U.fmtDelta(diff) + '</span>');
    }
    if (Number.isFinite(r.totals.tendered)) html += row('Paid', U.fmtMoney(r.totals.tendered, sym));
    if (Number.isFinite(r.totals.change)) html += row('Change', U.fmtMoney(r.totals.change, sym));
    $('#dlTotals').innerHTML = html;

    $('#rawText').textContent = state.ocr ? state.ocr.text : ($('#textInput').value || '');
  }

  function renderMath(report) {
    const sym = report.receipt.currency.symbol;
    const rows = report.math.checks.map((c) => {
      const pill = { pass: 'pass', warn: 'warn', fail: 'fail', skip: 'skip' }[c.status];
      const label = { pass: 'Pass', warn: 'Warning', fail: 'Fail', skip: 'Skipped' }[c.status];
      const num = (v) => (Number.isFinite(v) ? U.fmtMoney(v, sym) : '<span class="muted">—</span>');
      const deltaCls = !Number.isFinite(c.delta) ? '' : (Math.abs(c.delta) <= (c.tol || 0) ? 'pos' : 'neg');
      return '<tr>' +
        '<td class="desc">' + esc(c.label) + '</td>' +
        '<td class="mono muted">' + esc(c.equation || '') + '</td>' +
        '<td class="num">' + num(c.printed) + '</td>' +
        '<td class="num">' + num(c.computed) + '</td>' +
        '<td class="num ' + deltaCls + '">' + (Number.isFinite(c.delta) ? U.fmtDelta(c.delta) : '—') + '</td>' +
        '<td><span class="pill pill--' + pill + '">' + label + '</span></td>' +
      '</tr>';
    }).join('');
    $('#tblMath tbody').innerHTML = rows || '<tr><td colspan="6" class="muted">No arithmetic could be checked.</td></tr>';
  }

  function renderVisual(report) {
    const v = report.visual;
    const note = $('#visualNote');
    $('#tblRegions tbody').innerHTML = (v.regions || []).length
      ? v.regions.map((r) => '<tr>' +
          '<td class="num">#' + r.index + '</td>' +
          '<td class="mono">' + r.x + ', ' + r.y + ' · ' + r.width + ' × ' + r.height + '</td>' +
          '<td>' + (r.signals || []).map((s) => '<span class="pill pill--warn">' + esc(s) + '</span>').join(' ') + '</td>' +
          '<td class="num">' + r.score.toFixed(2) + '</td>' +
          '<td class="desc">' + esc((r.why || []).join(' · ')) + '</td>' +
        '</tr>').join('')
      : '<tr><td colspan="5" class="muted">No suspicious regions.</td></tr>';

    const cvOriginal = $('#cvOriginal');
    const cvEla = $('#cvEla');
    const cvBoxes = $('#cvBoxes');

    if (!v.ran || !state.canvas) {
      note.innerHTML = 'No image was supplied, so the pixel-level stages were skipped. Run an image through the detector to see error-level analysis, paper-tone mapping and typography forensics here.';
      [cvOriginal, cvEla, cvBoxes].forEach((c) => {
        c.width = 320; c.height = 120;
        const ctx = c.getContext('2d');
        ctx.fillStyle = '#0a0f17'; ctx.fillRect(0, 0, 320, 120);
        ctx.fillStyle = '#6d7f94';
        ctx.font = '13px system-ui, sans-serif';
        ctx.textAlign = 'center';
        ctx.fillText('not available in text mode', 160, 64);
      });
      return;
    }

    const st = v.stats || {};
    note.innerHTML = 'Error-level baseline (median) ' + st.errorLevelMedian + ', 99th percentile ' + st.errorLevelP99 +
      ' · paper tone ' + st.paperTone + ' ± ' + st.paperToneSpread +
      ' · ' + st.amountWordsCompared + ' amounts compared on glyph height, character width and right-edge alignment. ' +
      esc(v.note || '');

    drawVisual();
  }

  function drawVisual() {
    const visual = state.visual;
    if (!visual || !visual.ran || !state.canvas) return;
    const cvOriginal = $('#cvOriginal');
    const cvEla = $('#cvEla');

    cvOriginal.width = state.canvas.width;
    cvOriginal.height = state.canvas.height;
    cvOriginal.getContext('2d').drawImage(state.canvas, 0, 0);

    RS.visual.renderHeat(cvEla, visual.ela.norm, state.canvas.width, state.canvas.height, state.view.amp ? 8 : 1);

    RS.visual.drawOverlay($('#cvBoxes'), {
      image: state.canvas,
      regions: visual.regions,
      words: state.ocr ? state.ocr.words : [],
      showRegions: state.view.regions,
      showHeat: state.view.heat,
      showText: state.view.text,
      heat: visual.ela.norm,
      amplify: state.view.amp,
    });
  }

  function renderJson(report) {
    $('#jsonOut').textContent = JSON.stringify(report, null, 2);
  }

  /* ── tabs, filters, toggles ──────────────────────────────── */
  function selectTab(name) {
    $$('.tab').forEach((t) => {
      const on = t.dataset.tab === name;
      t.classList.toggle('is-active', on);
      t.setAttribute('aria-selected', on ? 'true' : 'false');
    });
    $$('.tabpanel').forEach((p) => p.classList.toggle('is-active', p.dataset.panel === name));
  }

  function wire() {
    /* modes */
    $$('.mode').forEach((btn) => {
      btn.addEventListener('click', () => {
        state.mode = btn.dataset.mode;
        $$('.mode').forEach((b) => {
          const on = b === btn;
          b.classList.toggle('is-active', on);
          b.setAttribute('aria-selected', on ? 'true' : 'false');
        });
        $$('.mode-panel').forEach((p) => p.classList.toggle('is-active', p.dataset.panel === state.mode));
        markReady();
      });
    });

    /* file input + drop */
    const dz = $('#dropzone');
    const input = $('#fileInput');
    dz.addEventListener('click', () => input.click());
    dz.addEventListener('keydown', (e) => {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); input.click(); }
    });
    input.addEventListener('change', () => {
      const f = input.files && input.files[0];
      if (!f) return;
      if (!/^image\//.test(f.type)) { showBanner('err', 'That file is not an image. ReceiptShield needs a PNG, JPG or WEBP.'); return; }
      hideBanner();
      setFile(f, f.name);
    });
    ['dragenter', 'dragover'].forEach((ev) => dz.addEventListener(ev, (e) => {
      e.preventDefault(); dz.classList.add('is-over');
    }));
    ['dragleave', 'drop'].forEach((ev) => dz.addEventListener(ev, (e) => {
      e.preventDefault(); dz.classList.remove('is-over');
    }));
    dz.addEventListener('drop', (e) => {
      const f = e.dataTransfer && e.dataTransfer.files[0];
      if (!f) return;
      if (!/^image\//.test(f.type)) { showBanner('err', 'That file is not an image.'); return; }
      hideBanner();
      setFile(f, f.name);
    });
    document.addEventListener('paste', (e) => {
      if (state.mode !== 'image') return;
      const items = (e.clipboardData && e.clipboardData.items) || [];
      for (const it of items) {
        if (it.type && it.type.indexOf('image/') === 0) {
          const f = it.getAsFile();
          if (f) { hideBanner(); setFile(f, 'pasted-image.' + (f.type.split('/')[1] || 'png')); }
          break;
        }
      }
    });

    /* samples */
    $('#btnGenuine').addEventListener('click', () => loadSample('genuine'));
    $('#btnTampered').addEventListener('click', () => loadSample('tampered'));
    $('#btnTextGenuine').addEventListener('click', () => {
      $('#textInput').value = RS.samples.docToText(RS.samples.genuineDoc());
      markReady();
    });
    $('#btnTextTampered').addEventListener('click', () => {
      $('#textInput').value = RS.samples.docToText(RS.samples.tamperedDoc());
      markReady();
    });

    /* run / reset */
    $('#btnRun').addEventListener('click', run);
    $('#btnReset').addEventListener('click', () => {
      if (state.file && state.file.url) URL.revokeObjectURL(state.file.url);
      state.file = null; state.canvas = null; state.ocr = null;
      state.receipt = state.math = state.visual = state.suspicious = state.report = null;
      state.truth = null;
      $('#fileInput').value = '';
      $('#textInput').value = '';
      renderDropzone();
      $('#sampleNote').hidden = true;
      $('#results').hidden = true;
      $('#btnReset').hidden = true;
      resetStages();
      setTag('idle');
      hideBanner();
      markReady();
      $('#detector').scrollIntoView({ behavior: 'smooth', block: 'start' });
    });
    $('#textInput').addEventListener('input', markReady);

    /* tabs */
    $$('.tab').forEach((t) => t.addEventListener('click', () => selectTab(t.dataset.tab)));

    /* filters */
    $$('.filters .chip').forEach((c) => c.addEventListener('click', () => {
      state.filter = c.dataset.filter;
      $$('.filters .chip').forEach((x) => x.classList.toggle('is-active', x === c));
      renderFindings();
    }));

    /* region deep-link */
    $('#findingsList').addEventListener('click', (e) => {
      const b = e.target.closest('[data-region]');
      if (!b) return;
      selectTab('visual');
      const row = $('#tblRegions tbody').querySelector('tr:nth-child(' + b.dataset.region + ')');
      if (row) {
        row.scrollIntoView({ behavior: 'smooth', block: 'center' });
        row.style.transition = 'background .3s';
        row.style.background = 'rgba(244,83,106,.16)';
        setTimeout(() => { row.style.background = ''; }, 1600);
      }
    });

    /* visual toggles */
    const bind = (id, key) => {
      const box = $('#' + id);
      box.checked = state.view[key];
      box.addEventListener('change', () => { state.view[key] = box.checked; drawVisual(); });
    };
    bind('tglBoxes', 'regions');
    bind('tglHeat', 'heat');
    bind('tglText', 'text');
    bind('tglAmp', 'amp');

    /* zoom */
    const dlg = document.createElement('dialog');
    dlg.className = 'zoom';
    dlg.innerHTML = '<button class="zoom__close" type="button" aria-label="Close">Close</button><img alt="Enlarged receipt view" />';
    document.body.appendChild(dlg);
    dlg.addEventListener('click', (e) => { if (e.target !== dlg.querySelector('img')) dlg.close(); });
    $$('.viewer canvas').forEach((c) => {
      c.style.cursor = 'zoom-in';

#!/usr/bin/env node
/* ==========================================================================
   ReceiptShield — local static server
   Dependency-free. The site is plain HTML/CSS/JS with no build step, but it
   must be served over http rather than opened from the filesystem so that the
   Tesseract web worker and the OCR model download behave normally.

   Usage:  npm start [-- --port 4177]
   ========================================================================== */
'use strict';

const http = require('http');
const fs = require('fs');
const path = require('path');

const ROOT = path.resolve(__dirname, '..');
const argv = process.argv.slice(2);
const portArg = argv.indexOf('--port');

// A PORT of "0" or "" in the environment means "not specified" here; falling
// through to it would silently bind a random port.
function resolvePort() {
  const candidates = [
    portArg !== -1 ? argv[portArg + 1] : null,
    process.env.PORT,
  ];
  for (const c of candidates) {
    if (c === null || c === undefined || c === '') continue;
    const n = Number(c);
    if (Number.isInteger(n) && n > 0 && n < 65536) return n;
  }
  return 4177;
}

const PORT = resolvePort();
const HOST = process.env.HOST || '127.0.0.1';

const TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.mjs': 'text/javascript; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.svg': 'image/svg+xml',
  '.png': 'image/png',
  '.jpg': 'image/jpeg',
  '.jpeg': 'image/jpeg',
  '.webp': 'image/webp',
  '.ico': 'image/x-icon',
  '.txt': 'text/plain; charset=utf-8',
  '.md': 'text/markdown; charset=utf-8',
  '.wasm': 'application/wasm',
};

const server = http.createServer((req, res) => {
  // WHATWG URL rather than the deprecated url.parse(): a malformed request
  // target throws here, which is exactly the 400 case.
  let pathname;
  try {
    pathname = decodeURIComponent(new URL(req.url, 'http://' + HOST).pathname);
  } catch (err) {
    res.writeHead(400, { 'Content-Type': 'text/plain; charset=utf-8' });
    return res.end('Bad request');
  }

  if (pathname.endsWith('/')) pathname += 'index.html';

  const target = path.join(ROOT, path.normalize(pathname).replace(/^(\.\.[/\\])+/, ''));
  if (!target.startsWith(ROOT)) {
    res.writeHead(403, { 'Content-Type': 'text/plain' });
    return res.end('Forbidden');
  }

  fs.stat(target, (err, stat) => {
    if (err || !stat.isFile()) {
      res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
      return res.end('404 — not found: ' + pathname);
    }
    res.writeHead(200, {
      'Content-Type': TYPES[path.extname(target).toLowerCase()] || 'application/octet-stream',
      'Content-Length': stat.size,
      'Cache-Control': 'no-cache',
    });
    fs.createReadStream(target).pipe(res);
  });
});

server.listen(PORT, HOST, () => {
  console.log('ReceiptShield running at http://' + HOST + ':' + PORT + '/');
  console.log('Serving ' + ROOT);
});

# ReceiptShield

**AI-based receipt fraud & tampering detection.** ReceiptShield reads a digital
receipt or bill and checks whether it may have been altered — and whether its
information is mathematically and logically consistent.

Everything runs in the browser. No server, no account, no API key, and the
receipt never leaves the device.

```
Receipt Upload → OCR Extraction → Item/Price/Tax Detection → Mathematical Validation
   → Visual Tampering Analysis → Suspicious Information Detection → Fraud Risk Report
```

Open `index.html` through a local server and you get a landing page plus a
working detector.

# or, without Node:
python -m http.server 4177 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4177/>.

Serve it over HTTP rather than opening the file directly: the OCR engine runs

treat `file://` workers differently.

The OCR engine (~4 MB of WebAssembly plus the English model) is fetched from

## Try it in ten seconds

works offline and with no personal data:

| Button | What it is |
| --- | --- |
| **Load genuine sample** | A clean, arithmetically consistent receipt. Scores **0 / 100**. |
| **Load tampered sample** | The same receipt with two amounts rewritten. Scores **100 / 100**. |

The tampered sample is built the way a real forgery happens. The receipt is
first encoded as a heavily compressed JPEG, as if it had been forwarded over a
messaging app. The two forged figures are then pasted on top from a separately
saved snippet, in a different typeface, on a background patch lifted from
another image, nudged off the value column — and the result is re-saved through
an image editor that stamps its name into the file.

Each fraud leaves four independent traces, and ReceiptShield finds all four:

| Traces left by the forgery | Stage that catches it |
| --- | --- |
| `₹200.00 → ₹700.00` breaks qty × unit and the item sum | Mathematical Validation |
| `₹708.50 → ₹1,708.50` breaks net + tax + rounding | Mathematical Validation |
| The gap is an exactly round `₹1,000.00` | Suspicious Information Detection |
| Pasted glyphs are bigger, wider and 8 px off the column | Visual Tampering Analysis (typography) |
| The patch's paper tone is 7 luminance levels darker | Visual Tampering Analysis (tone) |
| The pasted region has a different compression history | Visual Tampering Analysis (error level) |
| The file names `Adobe Photoshop 24.0` | Visual Tampering Analysis (container) |

informational, which is the number that actually matters. See

## The seven stages

### 1 · Receipt Upload
The image is decoded to a canvas at natural resolution, checked for a usable
size, and kept local. The original pixels are never pre-processed — only OCR
gets a cleaned copy, because the forensic stages must analyse what the user
actually has. The raw file bytes are retained separately for the container
check.

### 2 · OCR Extraction
Tesseract.js runs in a web worker. The OCR input is upscaled toward 2000 px and
given a grayscale percentile contrast stretch, both of which measurably improve
recognition on low-contrast scans. Tesseract returns word-level TSV, which is
parsed into words carrying a bounding box, a baseline and a confidence, then
grouped into lines and blocks with per-line typographic metrics.

### 3 · Item / Price / Tax Detection
Lines are classified as items, discounts, taxes, totals, payment rows or
metadata. Three things make the amount scanner reliable:

- **Dates and times are masked first**, so `12/03/2026` and `19:42` cannot be
  read as money.
- **Boundary tests** reject digits welded to letters, so `GSTIN
  27AABCU9603R1ZM` and `INV-2291` yield nothing.
- **Length rules**: without a currency symbol, decimal point or digit grouping,
  a 1–3 digit integer is a quantity and a 6+ digit integer is an identifier.
  On a row already identified as a money row (`Subtotal`, `GST`, `Total`) a
  bare integer is accepted, because `Subtotal 710` is perfectly normal print.

`35:5` is repaired to `35.5` — the classic OCR colon-for-decimal confusion.

### 4 · Mathematical Validation
Every equation the document asserts is recomputed from the document's own
figures and compared with the printed answer. Tolerance is scaled: two paise per
line for rounding noise, 0.2 % for sums of many lines.

- `qty × unit = line total` on every line
- `Σ line totals = subtotal`
- `subtotal − discount = taxable value`
- `net + tax + rounding = grand total`
- each tax line's own percentage applied to the net amount
- the rounding adjustment is within ±0.50
- payment covers the total; change equals paid − total
- no line carries a non-positive amount

A failing check is not just a flag: it reports the printed value, the
recomputed value, the delta and the tolerance used.

### 5 · Visual Tampering Analysis
Four independent passes over the pixels:

**Error-level analysis.** The image is re-compressed at JPEG quality 0.70 and
each pixel's change is measured. A region pasted after the original was saved
has a different compression history, so it moves differently. The critical
detail is the comparison *baseline*: error level rises with how much ink is in a
cell, so **a cell is only ever compared with cells carrying a similar amount of
ink**, in four bands (blank paper, light text, moderate text, dense text). The
grid is snapped to the 8×8 JPEG block lattice so cells straddling block
boundaries cannot inherit spurious residue.

Without that conditioning, ordinary text looks anomalous next to blank paper and
*every* receipt reads as tampered — the single most common way ELA produces
nonsense. With it, the clean sample produces exactly zero flagged cells.

**Paper-tone mapping.** Blank pixels are found per 14 px cell by variance, the
sheet's baseline tone is the median of them, and contiguous patches deviating
from it are reported with their measured luminance delta. A paste almost always
carries a slightly different white.

**Typography forensics.** Quantities and prices are compared on glyph height,
character width and right-edge alignment. Amounts are first clustered into
columns by right edge, so the unit-price column is never compared against the
total column. A figure is only accused when *two* weak signals agree or one
strong signal fires, because OCR word boxes wobble a few pixels horizontally and
glyph height is the only fully reliable measurement.

**Container check.** JPEG APP segments and PNG text chunks are scanned for
image-editor signatures (`CreatorTool`, `Software`, and 20+ product names).

### 6 · Suspicious Information Detection
Anomalies that are neither pure arithmetic nor pure pixels:

- repeated identical line items, or one description at two different prices
- a multi-item retail receipt with no tax line at all
- tax rows with no percentage, so the rate cannot be verified
- no invoice number *and* no date
- **a discrepancy that is an exactly round amount** — rounding and tax produce
  fractional differences; a person typing an edit produces `₹1,000.00`
- **a discrepancy equal to exactly one line item** — the signature of a line
  being added, doubled or retyped
- a grand total smaller than one of its own line items

### 7 · Fraud Risk Report
Findings are weighted by severity — critical 34, high 22, medium 12, low 5 —
summed into a 0–100 score and banded:

| Score | Band |
| --- | --- |
| 0–19 | Low risk |
| 20–44 | Elevated risk |
| 45–69 | Suspicious |
| 70–100 | High risk |

The report then shows every finding with the evidence behind it, the extracted
fields, the full arithmetic reconciliation, the flagged regions drawn on the
image, and a machine-readable JSON payload you can download.

## What this can and cannot claim

ReceiptShield is a **triage** tool. A flagged receipt is a reason to look closer,
not a finding of fraud. Compression, scanning, glare and phone cameras all
produce artefacts that resemble tampering.

**Strongest at:** edited amounts that break the arithmetic; text pasted from
another font; patches whose background tone does not match; files re-saved by an
image editor.

**Blind to:** a forger who retypes the whole receipt in one font, keeps the
arithmetic consistent and exports a clean PNG. Very low-resolution or heavily
compressed receipts defeat the pixel-level stages.

The two synthetic samples are built to be *demonstrative*, not adversarial. They
show each detector working on a trace it is designed for; they are not a
benchmark, and a passing score on them is not evidence of real-world accuracy.
